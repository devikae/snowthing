> 전국 스키장의 정보와 라이딩 경험을 나누고, 함께 즐길 유저를 찾을 수 있는 윈터스포츠 전용 커뮤니티

### 문제
1. 정보와 소통 공간의 파편화 및 노후화
- 스노보드 관련 정보는 카페, 오픈채팅, SNS, 디시인사이드 등에 흩어져 있고, 기존 대표 사이트들은 오래되어 https 접속조차 되지 않는 등 관리가 미비합니다.

2. 유저 유형별 탐색의 어려움
- 초보자는 장비, 강습, 슬로프 정보를 찾기 어렵고, 기존 이용자는 함께 탈 사람이나 리조트마다 개별적으로 흩어져 있는 웹캠·최신 현장 정보를 찾는 데 시간이 걸립니다.

`흩어진 정보와 웹캠, 소셜 기능을 게시글과 프로필 중심으로 모아, 사용자가 필요한 정보를 빠르게 찾고 유저 간 교류를 원활하게 할 수 있도록 합니다.

### Target User
1. 사용자 A : 기존 / 숙련 이용자 (시즌 보더 & 소셜 파트너 탐색 유저)

특정 베이스 스키장이 있고, 스키장을 자주(10회 이상) 찾는 이용자.
- needs: 
  - 여러 사이트 돌아다닐 필요 없이 실시간 웹캠/현장 정보를 한눈에 빠르게 확인.
  - 카풀 비용 정산 및 라이딩 스타일(카빙, 트릭, 설렁설렁 등)이 맞는 동행/카풀 파트너 탐색.

2. 사용자 B : 초보 / 입문 이용자 (정보 탐색 및 소통 유저)

스노보드에 막 입문했거나 시즌에 2~5회 정도 방문하는 초중급 보더.
- needs : 
  - 장비(데크/바인딩/고글 등) 추천, 리조트 이용 꿀팁, 강습 정보 등 검증된 정보 탐색.
  - 편하게 묻고 답변받을 수 있는 커뮤니티 공간
