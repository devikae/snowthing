- 상태: 초안 (사용자 검토 전). 실제 방침 화면과 버전(`shared/registration-policies/current.json`, 현재 `2026-11-10-v2`)은 바꾸지 않았다.
- 작성일: 2026-11-22 (KST)
- 관련 설계: `01_design.md` 7절 (개인정보와 키)
- 적용 시점: 2단계(OpenAI Moderation API)를 켜기 전(`SNOWTHING_MODERATION_API_ENABLED=true`). 1단계 규칙 검사만 켤 때는 외부로 보내는 내용이 없어 이 개정 없이도 된다.

## 1. 무엇이 바뀌나

| 지금 방침 (2026-11-10-v2) | 바뀌는 점 |
|---|---|
| 처리 위탁: AWS, Cloudflare, Kakao, Google, Naver | OpenAI를 더한다(게시물 자동 검토 보조) |
| 국외 이전 OpenAI 항목의 목적: AI 기능 제공(검색, 답변, 콘텐츠 생성) | 목적에 "부적절한 게시물 자동 검토"를 더하고, 이전 항목에 중고장터 글, 카풀 글을 더한다 |
| 거부 방법: 이메일로 요청 | 자동 검토에 대한 거부 방법과 그 결과를 따로 적는다 |

새 방침 버전 파일은 사용자 확인 뒤 `shared/registration-policies/2026-MM-DD-v3.json`으로 만들고 `current.json`을 바꾼다. 이번 PR에서는 만들지 않는다.

## 2. 처리 위탁 (추가할 문단)

> OpenAI: 게시물 자동 검토 보조. 이용자가 쓰거나 고친 게시글, 댓글, 중고장터 글, 카풀 글, 리조트 제보의 제목과 본문을 받아 광고, 음란, 불법 내용일 가능성을 점수로 알려 줍니다. 처리 지역은 미국이며, 자세한 내용은 아래 국외 이전 항목에 적었습니다.

## 3. 국외 이전 (OpenAI 항목을 바꾼 문단)

> 받는 자: OpenAI (미국, 연락처: privacy@openai.com).
> 이전 항목: 게시글과 댓글 내용, 라이브톡 질문, 리조트 제보 내용. 부적절한 게시물 자동 검토에는 게시글, 댓글, 중고장터 글, 카풀 글, 리조트 제보의 제목과 본문만 보냅니다. 작성자 정보(닉네임, 이메일, 회원 번호), IP 주소, 연락처 칸, 사진은 보내지 않습니다.
> 목적: AI 기능 제공(검색, 답변, 콘텐츠 생성)과 부적절한 게시물(광고, 도박, 음란, 불법 내용) 자동 검토.
> 시기와 방법: 해당 기능이 켜져 있을 때, 글을 쓰거나 고친 뒤 몇 분 안에 암호화된 네트워크(HTTPS)로 전송합니다.
> 보유 기간: OpenAI API 데이터 정책을 따릅니다. OpenAI는 API로 받은 내용을 학습에 쓰지 않고, 남용 감시를 위해 최대 30일 보관한 뒤 지웁니다. 눈팅은 검토 결과(판정과 점수)만 보관하고 보낸 본문은 따로 보관하지 않습니다.
> 쪽지 내용과 1:1 문의는 보내지 않습니다.

## 4. 거부 방법 (자동 검토 문단)

> 국외 이전을 원하지 않으면 아래 이메일로 요청할 수 있습니다. 자동 검토에 대한 거부를 요청하면 그 회원의 글은 OpenAI로 보내지 않고, 눈팅 서버 안의 규칙 검사와 운영자 검토만 거칩니다. AI 기능(검색, 답변)에 대한 거부 시에는 해당 기능 이용이 제한될 수 있습니다.

## 5. 사용자 확인이 필요한 것

1. OpenAI 보관 정책 문구: "학습에 쓰지 않음, 남용 감시 최대 30일"은 작성 시점에 알고 있던 OpenAI API 정책이다. 개정 전에 OpenAI의 최신 API 데이터 정책 문서를 다시 확인한다. 무보관(Zero Data Retention) 계약은 하지 않은 상태다.
2. 거부 처리 방식: 4절 문구대로라면 회원별로 2단계를 빼는 기능이 필요하다(지금 구현에는 없다). 다른 안은 "거부 시 게시물 작성이 제한될 수 있습니다"로 적는 것이다. 어느 쪽으로 할지 정해야 한다.
3. 비회원 글: 비회원은 거부 요청을 받을 계정이 없다. 익명게시판 글도 보낼지(지금 구현은 보낸다), 보내지 않을지 정해야 한다.
4. 고지 방법: 기존 방침 변경(2026-11-10-v2) 때와 같은 절차로 공지 글과 시행일을 정한다.
5. 처리 위탁과 국외 이전을 한 항목으로 합칠지: 지금 방침은 OpenAI를 국외 이전에만 적었다. 이 초안은 두 곳에 모두 적었다.
