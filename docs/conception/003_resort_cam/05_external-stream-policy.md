# 외부 영상 및 접근 정책

## 1. 기본 원칙

- SnowThing은 공식 공개 영상의 위치 정보만 관리합니다.
- 영상 파일, 세그먼트, 캡처 이미지를 서버에 저장하지 않습니다.
- 백엔드는 외부 영상을 프록시하거나 재송출하지 않습니다.
- 브라우저가 외부 원본 호스트에 직접 연결합니다.
- 초기 링크 후보는 `ski-resort.kr`과 `ski.atik.kr`의 공개 목록을 참고하되 실제 저장값은 원본 영상 또는 공식 페이지 URL로 기록합니다.

## 2. 호환성 판정

| 조건 | 처리 |
|---|---|
| HTTPS HLS와 CORS 허용 | HLS |
| 공식 YouTube 영상 | YOUTUBE |
| 외부 프레임 허용 | IFRAME |
| HTTP 전용, 프레임 차단, 토큰 의존 | EXTERNAL_LINK |

타 사이트에서 재생된다는 이유만으로 SnowThing에서도 재생된다고 가정하지 않습니다. Origin, Referer, CORS, CSP, 만료 토큰을 실제 SnowThing HTTPS Origin에서 확인합니다.

## 3. 브라우저 보안

- `sourceUrl`을 HTML 문자열로 삽입하지 않습니다.
- iframe에는 필요한 최소 `sandbox`와 `allow` 속성을 적용합니다.
- 새 탭은 `target="_blank" rel="noopener noreferrer"`를 사용합니다.
- CSP의 `connect-src`, `media-src`, `frame-src`에는 검증된 호스트만 추가합니다.
- URL에 인증 토큰이나 개인정보를 저장하지 않습니다.

## 4. 장애 정책

- 외부 재생 실패를 백엔드 장애로 취급하지 않습니다.
- 자동 무한 재시도는 금지합니다.
- 사용자 재시도와 원본 페이지 이동을 제공합니다.
- 리조트 전환 시 HLS 인스턴스, 이벤트 리스너, iframe을 정리합니다.
- 비활성화는 DB 값으로 처리하며 행을 물리 삭제하지 않아도 됩니다.

## 5. 운영 고지

화면에 다음 취지의 고지를 둡니다.

> 각 영상은 리조트가 외부에서 제공하는 원본에 직접 연결됩니다. SnowThing은 영상을 저장하거나 재송출하지 않으며, 제공처 사정에 따라 영상이 중단되거나 변경될 수 있습니다.
