# 리조트캠 결정 요구

## 확정된 결정

- 브랜치: `feature/resort-cam`
- 설계 위치: `docs/conception/003_resort_cam`
- DB 마스터 데이터 방식
- 기존 `Resort` 확장과 `ResortCamera` N:1 구조
- 카메라 코드·이름 사용, 슬로프 마스터는 제외
- 공개 조회, 관리자 기능은 추후 개발
- 12개 리조트 지원
- 리조트 전체 보기와 개별 카메라 보기
- PC 가시 영역 음소거 자동재생, 최대 6개
- 모바일 사용자 선택 재생
- 영상 저장·프록시·재송출 금지

## 구현 전 확인할 운영 데이터

아래 항목은 제품 정책 결정이 아니라 외부 소스의 실제 호환성 확인 결과로 확정합니다.

1. 카메라별 최종 `source_type`
2. SnowThing HTTPS Origin에서 재생 가능한 최종 `source_url`
3. 재생 실패 시 이동할 공식 `external_page_url`
4. 계절 종료 카메라와 비스키 카메라의 초기 활성 여부
5. CSP에 추가할 외부 호스트 목록

호환되지 않는 소스는 임의 프록시로 우회하지 않고 `EXTERNAL_LINK`로 낮춥니다.
