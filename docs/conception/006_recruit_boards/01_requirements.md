# 동호회 및 시즌방 홍보 게시판 요구사항

## 1. 목적

스노우보드/스키 커뮤니티에서 동호회원(크루원) 모집 및 시즌방(투자자·멤버) 모집을 위한 순수 공개 홍보 플랫폼을 제공합니다.
플랫폼은 폐쇄형 크루 관리나 금전 계약에 직접 개입하지 않고, 기존 게시판 인프라(`Post`)를 재사용하여 정보 공유와 댓글 소통의 장을 지원합니다.

## 2. 사용자 시나리오

1. **동호회 홍보글 작성**:
   - 로그인한 회원이 글쓰기 화면에서 '동호회 모집' 카테고리를 선택합니다.
   - 크루 소개, 주 베이스 리조트, 라이딩 성향, 지원 자격, 오픈카톡 링크 등을 제목 및 본문에 자유롭게 작성합니다.
   - 익명 작성은 지원되지 않으므로 회원 본인의 닉네임으로 등록됩니다.
2. **시즌방 홍보글 작성**:
   - 로그인한 회원이 글쓰기 화면에서 '시즌방 모집' 카테고리를 선택합니다.
   - 대상 리조트, 숙소 위치, 모집 인원 및 성비, 투자 비용, 방 규칙 등을 제목 및 본문에 작성합니다.
   - 익명 작성은 지원되지 않으므로 회원 본인의 닉네임으로 등록됩니다.
3. **목록 및 상세 조회**:
   - 방문자는 '전체글' 탭 또는 전용 '동호회 모집', '시즌방 모집' 탭에서 홍보글 목록을 열람합니다.
   - 상세 페이지에서 본문 내용을 확인하고 댓글/대댓글을 통해 문의 및 소통합니다.

## 3. 기능 요구사항

| ID | 요구사항 |
|---|---|
| RECRUIT-F-001 | `post_category`에 '동호회 모집'(`CREW`) 및 '시즌방 모집'(`SEASON_ROOM`) 카테고리를 제공한다. |
| RECRUIT-F-002 | 두 게시판은 **로그인 회원만 작성 가능**하며, 비회원 작성 및 익명(`isAnonymous = true`) 작성을 원천 차단한다. |
| RECRUIT-F-003 | 익명 글쓰기 시도 시 표준 비즈니스 에러 코드 `POST_006` (`ANONYMOUS_POST_NOT_ALLOWED`)를 반환한다. |
| RECRUIT-F-004 | 기존 게시글 수정 시에도 익명 글이 `CREW`나 `SEASON_ROOM` 카테고리로 변경되는 것을 차단한다. |
| RECRUIT-F-005 | '전체글' 목록 조회 시 두 카테고리의 게시글도 함께 정상 노출된다 (방식 A). |
| RECRUIT-F-006 | 상단 내비게이션 드롭다운 메뉴 및 게시판 카테고리 탭에 '동호회 모집', '시즌방 모집'을 노출한다. |
| RECRUIT-F-007 | 글쓰기 화면에서 두 카테고리 선택 시 '익명으로 작성' 체크박스 및 익명 비밀번호 입력을 숨긴다. |

## 4. 비기능 요구사항

- **무결성 및 안정성**: 신규 테이블 추가 없이 기존 검증된 `Post`, `Comment`, `PostImage` 인프라를 100% 재사용하여 시스템 복잡도를 최소화한다.
- **예외 처리 표준화**: 문자열 리터럴 예외를 금지하고 `ErrorCode.ANONYMOUS_POST_NOT_ALLOWED`와 `CustomAuthException`으로 일원화한다.
- **DTO 불변성**: DTO 생성 시 컬렉션 방어적 복사 원칙을 준수한다.
- **계층 분리**: 서비스 레이어에서 세션/서블릿에 직접 결합하지 않는다.
