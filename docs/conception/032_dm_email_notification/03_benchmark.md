# 쪽지 메일 동기 기준선과 Outbox 비교

- 측정일: 2026-11-17
- 환경: 로컬 Windows, Docker MySQL 8.0, 가짜 SES HTTP 서버. 운영 수치가 아니다.
- 실행: `./gradlew test -PincludeBenchmark --tests '*DmMailSyncBaselineBenchmarkTest' --tests '*DmMailOutboxBenchmarkTest'`
- 원본: `backend/build/benchmark/dm-mail-sync-baseline.json`, `dm-mail-outbox.json`

## 조건

| 항목 | 값 |
|---|---|
| 쪽지 보내기 요청 | 60건, 받는 사람은 모두 다름(쿨다운 묶음이 끼지 않게) |
| 동시 실행 | 6 |
| 가짜 SES 응답 지연 | 1000ms (수락 후 응답) |
| SES 제한 시간 | 시도 3초, 전체 5초 (운영과 같음), SDK 재시도 0회 |
| DB 커넥션 풀 | 5 (테스트 설정) |
| Outbox 워커 | 프로세스 안 한 개, 1초 간격 폴링 |
| 측정 대상 | `DirectMessageService.send` 호출 시간 (HTTP 계층 제외) |

동기 기준선은 `snowthing.dm-mail.delivery-mode=sync-baseline`이다. 쪽지 트랜잭션 안에서 SES를 바로 부른다.

## 결과

### 쪽지 보내기 지연

| 방식 | p50 | p95 | 최대 | 60건 전체 | 오류 |
|---|---|---|---|---|---|
| 동기 기준선 | 1038ms | 1965ms | 2049ms | 12.3초 | 0 |
| Outbox | 14ms | 30ms | 46ms | 0.18초 | 0 |

- 동기 기준선은 SES 지연 1초가 응답에 그대로 더해진다.
- 동기 기준선의 p95가 2초 가까운 것은 커넥션 풀 때문이다. 요청 6개가 동시에 들어오면 5개가 SES를 기다리는 동안 커넥션을 쥐고 있어, 나머지 하나는 커넥션을 1초 가까이 기다린다. SES가 느려지면 쪽지와 상관없는 API까지 커넥션을 기다리게 되는 경로다.
- 표본이 60건이라 p99는 적지 않는다.

### 알림 전달 지연 (Outbox)

| 항목 | 값 |
|---|---|
| 적재부터 SES 수락 기록까지 p50 | 26.9초 |
| p95 | 57.9초 |
| 최소 | 0.8초 |
| 관찰한 최대 대기 건수 | 60 |
| 가짜 SES 요청, 수락 | 60, 60 |
| 최종 상태 | ACCEPTED 60 |

워커 하나가 받는 사람을 한 명씩 차례로 처리하므로, 처리량은 대략 1 / SES 응답 시간이다. 이 조건에서는 초당 1통이고, 60건이 한꺼번에 들어오면 마지막 건은 약 1분 뒤에 나간다.

## 해석

| | 동기 기준선 | Outbox |
|---|---|---|
| 쪽지 응답 | SES 지연만큼 느려짐 | SES와 무관 |
| DB 커넥션 | SES 대기 동안 점유 | 짧은 트랜잭션만 |
| 쪽지 커밋 후 앱 종료 | 메일 요청 기록 없음 | DB 행이 남아 재기동 후 처리 |
| 메일이 나간 뒤 쪽지 롤백 | 가능 | 불가능 (커밋 후에만 발송) |
| 알림 지연 | 즉시 | 폴링 간격 + 대기 건수 × SES 응답 시간 |
| DB 비용 | 없음 | 쪽지마다 INSERT 1, 폴링 쿼리, 행 정리 |

Outbox는 쪽지 응답과 SES를 떼어 놓는 대신 알림 지연을 받아들인다. 지금 서비스의 쪽지량에서는 한꺼번에 60건이 몰리는 일이 드물어 1초 안팎이 일반적이다. 몰림이 잦아져 지연이 문제가 되면, 받는 사람 처리를 작은 스레드 풀로 병렬화하거나(선점 단위가 받는 사람이라 정합성은 그대로다) SES 비동기 클라이언트를 검토한다. 먼저 대기 건수와 가장 오래된 대기 시간을 지표로 본다.

## 제외한 측정

첫 실행은 테스트용 짧은 제한 시간(시도 0.6초, 전체 0.9초)으로 돌아, 동기 기준선은 SES 호출이 0.6초에 끊겼고(p50 637ms) Outbox는 60건이 모두 UNKNOWN이 됐다. 수치에서 제외했다. 이 관찰은 `02_verification.md` 4절에 적었다.
