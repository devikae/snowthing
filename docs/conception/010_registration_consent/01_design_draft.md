# 가입 전 동의 설계 초안

- 신규 가입 전 만 14세 이상 자기 확인 및 개인정보 수집·이용 동의를 받는다.
- 일반 이메일 가입은 화면과 서버에서 필수 동의를 검증하며, 회원 생성·인증 토큰 소비·동의 이력 저장을 같은 트랜잭션에서 처리한다.
- 기존 회원의 로그인은 유지하고 소셜 신규 가입에도 동의를 적용해야 한다.
- 동의 기록은 member_registration_consent 테이블에 처리방침 버전·연령 확인·선택 마케팅 동의·확인 시각을 저장한다. 017 마이그레이션을 먼저 적용해야 한다. 기존 회원의 동의를 임의로 생성하지 않는다.
- 개인정보 보관·삭제 기간 및 외부 서비스 처리 현황을 확인하고 처리방침을 완성해야 한다.
- 문의 창구: SnowThing 운영팀, 82snowthing@gmail.com.

## PR 검토 시 남은 사항

- 기존 OAuth 신규 회원 생성 경로에는 이 동의 흐름이 연결되지 않았다. 이 PR에서 소셜 가입 동의까지 완료했다고 주장하지 않는다.
- 개인정보처리방침은 운영 보관·파기·위탁·국외 이전 현황 확인이 남은 초안이다. 법률 준수 완료 또는 운영 준비 완료로 판단하지 않는다.
