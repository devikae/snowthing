## 환경상 한계와 별도 점검

실제 AWS 자격증명·CloudFront 정책을 이용한 업로드는 이번 로컬 작업에서 실행하지 않았다. 이미지 변환은 실제 바이트로, S3 전송은 mock으로 검증했다. 요청 제한은 단일 인스턴스 메모리 기준이다. S3 고아 파일 삭제 배치는 가져오지 않았다. Spotless의 worktree 인식 실패와 여러 Spring 테스트 컨텍스트의 공유 스키마 종료 경고는 별도 인프라 점검 항목이다.
