# PR #47 CodeRabbit 검토 내역

2026-11-03 기준 인라인 리뷰 15개와 리뷰 본문의 후속 의견을 최신 코드와 대조했다. 칭찬 및 보존 요청은 변경 사유로 사용하지 않았다.

| 의견 | 처리 |
|---|---|
| 변환 구간만 게이트로 제한, 게이트 획득 후 예산 검사 | 기존 ba92007 반영 확인. S3 업로드는 게이트 밖에서 실행 |
| imageKeys 원소 검증과 방어적 복사 | 기존 반영 확인. 승인 설계의 512자 상한 유지 |
| 작은 사진 확대 방지 | 기존 반영 확인. EXIF 수정 후에도 작은 이미지 테스트 유지 |
| 본문 키 중복 제거·30개 상한·일관된 잠금 순서 | 기존 반영 확인. 정렬 잠금 유지 |
| 공통 한도 장애 안내 문구 | 기존 반영 확인 |
| 익명 비밀번호 수정의 기존 사진 재사용 | 기존 반영 및 통합 테스트 확인 |
| 기존 CloudFront 프로필 동작도 캐시 비활성화 | 기존 스크립트 반영 확인. 이번 작업에서 AWS 설정 변경 없음 |
| Spotless 실패 (엔티티·수명주기·보안 테스트) | spotlessApply로 전체 변경 파일 정리 |
| EXIF 방향 손실 | 원본 스트림 변환 및 orientation=6 JPEG 회귀 테스트 |
| 썸네일 무한 재시도·입력 검증 불일치·예산 낭비 | 같은 키 정규식, attempts 및 백오프·영구 오류 중단·예산 대기 적용 |
| 본문에만 참조된 이미지가 삭제됨 | 026 참조 테이블, 일반 게시글·장터 저장 연결, 인덱스 조회 및 보존·제거 테스트 |
| 타인 업로드 테스트가 NPE에도 통과함·CSRF 테스트 누락 | 정상 업로드 201·본인 변경·타인 미변경 테스트 유지. 중복 테스트를 CSRF 403 및 이미지 서비스 미호출 테스트로 교체 |
| MySQL 8의 CREATE INDEX IF NOT EXISTS 미지원 | 023과 같은 information_schema 확인 후 생성. 재실행 검증 |
| revision 경합·미래 lease 테스트 없음 | 생성 중 queue, 실패 중 queue, 미래 lease 회귀 테스트 |
| 고아 정리가 시간당 20개로 제한됨 | 2분 상한 내 배치 반복·커서 전진·실패 lease, 45개 배치 테스트 |
| 레거시 이미지 반복 본문 스캔 | 실행 중 본문 스캔 제거. 첨부와 본문 참조 인덱스 조회. 백필 스캔은 마이그레이션에서 한 번 실행 |
| 전역 예산 공격·관측성 | 전역 거절 사유와 FILE_007 유지. 프로필·게시글 전용 예산 분리 및 공통 비용 상한 유지. 신규 계정·IP별 버킷과 회귀 테스트 추가. 분당 집계 EMF와 운영 CloudWatch Agent 수집·SNS 경보 2개 적용 |

2026-11-03 추가 승인으로 앞서 보류한 종류별 예산 분리·가입 직후 계정/IP 한도·운영 경보·실측까지 반영했다. 운영 DB 읽기 전용 실측에서 소프트 삭제 포함 게시글 86개, 첨부 및 레거시 백필 키 각 2개를 확인했다. 실행 계획과 조회 시간은 06_production_image_inspection.json에 기록했다. 전용 로그 그룹 7일 보관과 SNS 연결 경보 2개를 생성했고 Agent running/configured를 확인했다.

이 문서는 리뷰 제안의 코드·설정 반영 내역이다. 앱·DB 마이그레이션은 PR 병합·배포 과정에서 적용되며 이번 작업에서 운영 앱을 교체하거나 DB를 수정하지 않았다. 따라서 새 앱의 실사용 메트릭과 신규 테이블의 운영 실행 계획은 배포 이후에만 확인할 수 있다. CodeRabbit 자동 재리뷰의 해결 판정과도 구분한다.
