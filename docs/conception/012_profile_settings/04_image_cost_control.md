# 이미지 저장 및 비용 악용 방지

사용자 승인 기준은 프로필 변경 요청 24시간 고정 구간당 5회, 일반 사진 요청 계정별 시간당 30회다. 변경 실패·기본 사진 초기화도 요청 횟수에 포함한다. 서버를 재시작해도 유지되는 request_budget_window를 사용하며 제한 저장소 장애 시 업로드를 허용하지 않는다. 사진 전체 업로드는 시간당 300회·24시간당 1,000회 상한을 함께 검사한다. 구간 경계에서 요청이 집중될 수 있어 이미지 처리는 프로세스당 동시 2개로 제한한다.

프로필 변경은 서비스 전체에서도 24시간당 30회로 제한해 다중 계정을 통한 CDN 무효화 요청 비용을 제한한다. 사용량 증가 시 이 상한과 비용 예산을 함께 검토한다.

## 일반 사진 등록과 원자성

기존 POST /api/v1/images의 응답 imageUrl·imageKey 계약은 유지한다. POST /api/v1/images/keep-alive는 인증·CSRF를 요구하며 imageKeys 문자열 배열(최대 10개)을 JSON으로 받아 본인의 유효한 업로드를 연장하고 204를 반환한다. 계정별 시간당 60회로 제한한다. 소유권 불일치·삭제 중인 사진은 입력 오류로 거절한다.

024의 post_image_upload는 image_key PK, owner_email, state, due_at 및 예정 시각 인덱스를 가진다. 이미지 저장 전에 예약을 별도 트랜잭션으로 커밋한다. 새 사진 키는 public/posts/originals/m-UUID.jpg이며 썸네일은 public/posts/thumbnails/m-UUID.jpg다. URL 승격·복사 대신 같은 키를 유지해 글 저장과 S3 복사 사이의 실패 구간을 줄인다.

게시글·장터 저장 트랜잭션에서 업로드 행을 키 순서로 잠그고 소유자와 PENDING 상태를 검증한다. 삭제 중·삭제 완료·존재하지 않는 새 키는 연결할 수 없다. 본문에 직접 입력한 관리 대상 이미지 경로도 검사한다. 기존 파일은 보수적으로 호환하며 024는 DB에 연결된 기존 첨부를 등록한다. 기존 미참조 파일은 별도 조사 결과로만 관리한다.

## 보관과 정리

미연결 사진은 마지막 연장으로부터 1시간 뒤 정리 대상이다. 글 작성·수정 화면은 열려 있는 동안 10분마다 첨부 사진의 유효 시간을 연장한다. 임시저장 문서 기능은 추가하지 않는다. 주기 작업은 분당 최대 50행을 선택하고 DB 참조와 본문 참조를 확인한다. 삭제된 게시글도 복구 가능성을 위해 참조로 유지한다. 현재 연결된 사진은 예정 시각을 연장한다. 제거된 사진은 다음 만료 시점에 정리한다.

삭제 대상은 행 잠금 안에서 DELETING으로 전환하고 10분 임대를 기록한 뒤 DB 트랜잭션 밖에서 S3 원본·썸네일을 삭제한다. 실패하면 임대 만료 후 재시도한다. 완료는 DELETED로 남겨 오래된 작성 요청의 재연결을 거절한다. 새 m- 키의 삭제 기록은 7일 후 제거하며, 삭제 기록이 없어도 존재하지 않는 새 키의 연결은 거절한다. 기존 키의 삭제 기록은 유지한다.

S3 수명주기는 public/posts/ 전체를 만료하지 않는다. 애플리케이션이 삭제 대상으로 확정한 뒤 붙이는 snowthing-cleanup=ready 태그에만 1일 만료 규칙을 적용한다. S3 수명주기는 서버의 1시간 정리를 대체하는 즉시 실행 장치가 아니다.

## 이미지 변환과 캐시

새 일반 사진은 최대 1920×1920 범위의 JPEG 품질 0.82로 변환한다. 원본 파일을 추가 보관하지 않으며 썸네일은 최대 320×320 JPEG 품질 0.8이다. 파일 특성에 따라 변환 후 바이트 수가 항상 작아지는 것은 아니다. 파일당 5MB, 한 변 10,000px·총 2,500만 픽셀 검증을 먼저 수행한다. 일반 관리 사진은 캐시 max-age=3600으로 장기 잔류를 줄인다. 이전 파일의 저장 헤더는 변경하지 않는다.

프로필은 최대 320×320 JPEG 품질 0.8 하나만 보관한다. 교체·초기화 시 이전 파일을 DB 정리 작업에 기록하고 S3 삭제 및 CloudFront 무효화를 재시도한다. 프로필 경로에는 캐시 비활성 정책을 적용한다.

## 운영

- 역할 권한은 프로필 및 게시글 사진 경로의 삭제·태그와 특정 CloudFront 배포 무효화로 제한한다.
- 운영에 있던 월 35 USD 예산의 50%·80%·100% 실제 비용 알림에 82snowthing@gmail.com 수신자를 추가했다. 예산은 업로드 차단 장치가 아니다.
- 공개 CDN의 모든 다운로드 비용에 대한 절대 상한을 보장하지 않는다. 업로드 상한과 비용 알림으로 통제하며, 실제 읽기 공격이 확인되면 CDN 요청 차단을 별도로 수행해야 한다.
- 배포 시 023·024 마이그레이션, 배포 ID 환경변수 반영과 헬스체크, 이미지 생성·교체·정리 관측이 필요하다. 이 문서는 배포 완료를 의미하지 않는다.
