# 이메일 인증과 비밀번호 재설정

이 디렉터리는 Amazon SES를 이용한 회원가입 이메일 인증과 비밀번호 재설정 설계를 관리합니다.

## 결정 요약

- 로그인 ID는 기존과 같이 이메일을 사용합니다.
- 신규 회원은 6자리 인증번호를 확인한 뒤에만 가입할 수 있습니다.
- 비밀번호 재설정은 가입 여부를 외부에 노출하지 않습니다.
- 발송은 서울 리전 Amazon SES v2 API를 동기 호출합니다.
- Outbox와 Inbox는 현재 범위에서 제외합니다.
- 인증번호와 일회용 토큰은 원문을 저장하지 않습니다.
- 기존 회원은 로그인을 차단하지 않고 이메일 인증 상태를 점진적으로 확보합니다.
- 이메일 주소 변경과 이메일 ID 찾기는 제공하지 않습니다.
