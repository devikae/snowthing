# 라이더 도구와 초기 유입 (2026-11-01)

## 범위·데이터 경계

사용자가 시즌권 본전·데크 사이즈 계산기와 초기 유입 기능의 자율 설계/구현을 승인했다. 기존 전체 설계에서 회원·게시판·리조트 마스터와 이미지·인증 관계를 확인했으며, 도구는 비로그인 프론트 계산으로 제공한다. 새 DB/API나 프로필 저장은 필요 없다. 결과 URL에는 사용자가 공유를 누른 시점의 계산 입력만 포함한다. 이름·이메일·회원 ID는 포함하지 않는다.

## 시즌권 계산

- 시즌권 실제 결제액, 할인 적용 리프트권 1회 가격, 시즌권 이용 시/개별권 이용 시 각각의 1회 부대비용, 이미 방문한 횟수, 예상 총 방문 횟수를 입력한다.
- 차액 절감액 = 리프트권 + 개별권 부대비용 − 시즌권 부대비용.
- 방문 N회의 시즌권 총비용 = 시즌권 가격 + N × 시즌권 부대비용. 개별권 총비용 = N × (리프트권 + 개별권 부대비용).
- 시즌권이 더 비싸지 않게 되는 최소 횟수는 차액이 양수일 때 ceil(가격/차액)이다. 차액이 0 이하이면 가격이 양수인 시즌권의 비용 회수는 불가능하다. 무료 시즌권은 부대비용에 따라 최초 동률과 이후 유불리를 구분한다.
- 목표 횟수까지 남은 방문, 현재·예상 기준 1회 비용, 방문 횟수별 비용표를 제공한다. 0회에서 1회 비용은 null이다. 렌털·보험 등 동일하게 발생하는 비용도 비교하려면 두 부대비용에 같은 값을 넣는다.
- 입력은 유한한 정수, 원 단위 금액 0~1억원, 방문 0~730회. 이미 방문한 횟수는 예상 총 방문보다 클 수 없다. 사용자 입력 가격을 사용하므로 현재 리조트 가격을 임의 제공하지 않는다.

## 데크 계산의 근거

- 최신 사용자 요청: 라이딩 성향 선택도 제거한다. 입력은 체중·부츠 mm 두 개만 받고 계산 결과에서 짧은 쪽(그라운드 트릭/조작성), 중간(올라운드·파크/균형), 긴 쪽(라이딩/안정성)을 함께 보여준다. 기존 style/level 공유값은 무시하고 새 공유/자동 초안에 사용자 성향을 추정해 넣지 않는다.
- 구간 숫자는 제조사의 성향별 추천값이 아니라 기존 체중 참고 범위를 읽기 쉽게 나누는 표시 규칙이다. 정수 cm 범위의 양 끝 각 floor(전체 정수 길이 수/4), 가운데는 나머지로 나눠 누락/겹침을 없앤다. 예: 152~159는 152~153 / 154~157 / 158~159. 3개 미만의 길이 또는 상한 없는 165cm 이상은 임의 구간/최댓값을 만들지 않는다. 실제 판매 길이가 이 정수 범위에 모두 있다는 의미도 아니다. 파크의 기물/큰 점프 차이와 모델별 권장 체중·구조 차이는 짧게 표시한다. 이 규칙은 앞서 남긴 성향·실력 입력 설계를 대체한다.

- 2026-11-01 사용자 요청으로 실력 구분(입문·초보/중급/상급)을 제거했다. 입력은 체중·부츠 mm·라이딩 성향이며 실력에 따른 결과 덮어쓰기와 초안/새 공유 링크의 실력 필드를 없앴다. 과거 링크의 level 값은 무시하고 나머지 조건으로 복원한다. 아래의 실력 관련 설명은 초기 설계 이력이며 현재 적용하지 않는다. 성향별 길이 추천 로직 개선은 별도 후속 항목으로 유지한다.

- Burton 공식 구매 가이드: https://www.burton.com/en-us/blogs/the-burton-blog/snowboard-buying-guide
- SPREAD 공식 모델·진단 안내: https://www.spreadboard.net/
- 2026-11-01 자료 확인. 길이는 체중 구간의 참고 범위를 보여주며, 제조사·모델별 체중 표가 우선한다. 보편적인 최적 사이즈나 그라운드트릭용 임의 cm 보정치를 지어내지 않는다. 신장·성별만으로 길이를 결정하지 않는다.
- 체중으로 겹치는 공식 표 구간을 모두 찾는다. 성향과 실력은 참고 범위 내에서 짧은 쪽/중간/긴 쪽을 검토하는 이유와 주의사항을 바꾼다. 그라운드 트릭·올라운드·파크·라이딩을 분리하고 파크의 기물과 큰 점프의 요구가 다름을 안내한다.
- 부츠 크기는 폭 확인에 사용한다. 실제 부츠 표기와 브랜드별 차이를 구분하며 모델별 권장 부츠·허리폭·바인딩 적합 확인을 제공한다. 체중 자료 범위 밖에서는 수치 외삽을 하지 않는다.

## 유입 및 연결

- /tools 허브와 /tools/season-pass, /tools/deck-size 공개 경로. 실제 도구가 준비된 후 메뉴에 노출한다.
- 결과를 텍스트·URL로 공유하며 클립보드 실패는 복사 가능한 입력으로 대체한다. 본문 개인정보가 없는 계산 결과를 게시판 질문 초안으로 옮기는 동작은 사용자가 선택한다. 자동 게시하지 않는다.
- 기본 페이지는 검색 가능한 제목/설명을 제공한다. 공유값은 URL fragment에 넣어 HTTP 쿼리 로그나 Referer로 전송되지 않게 하고 기존 query 형식도 읽을 수 있게 한다. canonical은 기본 페이지로 지정한다. 공유받은 사람은 입력값을 볼 수 있다는 안내를 표시한다.
- 이벤트 측정은 사용자의 가격·체중 등 원시 입력을 외부로 보내지 않는 기준으로 설계한다. 광고·외부 홍보는 실행 계획 문서만 작성한다.

## 검증
