# 초기 라이더 유입 실행안

## 지금 제공하는 진입 경로

1. 비로그인 방문자가 라이더 도구에서 시즌권 손익이나 데크 참고 사이즈를 계산한다.
2. 계산 결과를 링크로 공유한다. 가격·체중 등 원시 입력은 URL fragment에 넣어 서버 쿼리 로그로 보내지 않는다. 공유받는 사람도 가입 없이 조건을 바꾸어 계산한다.
3. 데크 결과에서 질문 초안을 확인한다. 사용자가 공개할 내용을 검토하고 장비 질문 쓰기를 선택한다.
4. 로그인 전 작성 초안은 브라우저 세션에 보관하며 로그인 후 글쓰기로 복귀한다. 자동 게시하지 않는다.
5. 현장 정보가 필요한 방문자는 도구의 오늘의 설질·카풀 링크로 이동한다.

회원가입 전 계산을 막지 않는다. 실제 질문이나 제보 작성이 필요해졌을 때 가입하는 흐름이다. 댓글 수·활성 사용자·인기 순위 같은 증거 없는 숫자나 가짜 후기를 추가하지 않는다.

## 첫 4주 운영 제안

### 공개 전

- 실제 운영 가입 동의·개인정보 보관 정책·소셜 신규 가입 동의 흐름과 이미지 권한을 먼저 확정한다. 이번 로컬 구현은 운영 공개 승인이 아니다.
- 모바일에서 계산→공유→질문 초안→로그인→글쓰기 흐름을 검수한다.
- 공지에 서비스 목적, 신고/문의 방법과 질문 예시를 실제 운영자 명의로 올릴 준비를 한다. 시드 데이터는 테스트 표시를 유지하고 운영 게시글로 위장하지 않는다.

### 1주차: 작은 사용자 집단에서 확인

- 운영자가 접근할 수 있는 실제 라이더 5~10명에게 허락을 받고 도구를 사용해 달라고 요청하는 계획을 세운다. 이 문서 작성 과정에서는 연락하지 않는다.
- 사용자가 시즌권 가격을 어디서 확인하는지, 부츠 US 표기가 어려운지, 질문 초안의 어떤 항목을 지우는지 관찰한다.
- 특정 리조트의 주말 방문자처럼 답변을 제공할 수 있는 집단부터 시작한다. 커뮤니티의 모든 게시판을 동시에 채우려 하지 않는다.

### 2주차: 검색으로 반복되는 질문 해결

- 시즌권 본전, 시즌권 1회 비용, 데크 체중별 길이, 부츠와 데크 폭처럼 실제 도구가 답하는 검색 의도에 맞춰 제목/설명/계산 근거를 다듬는다.
- 제조사 원문을 베껴 게시글을 대량 생성하지 않는다. 계산 예시와 한계를 직접 작성하고 출처와 자료 확인일을 남긴다.
- 운영자가 공개를 승인한 뒤에만 검색 등록과 실제 검색 노출을 확인한다. Search Console 설정·소유권 확인은 이번 로컬 작업 범위에서 수행하지 않는다.

### 3주차: 공유가 다시 사용으로 이어지는지 확인

- 도구 결과가 들어간 실제 질문에 답변할 수 있는 운영 시간대를 정한다. 24시간 응답 등 지킬 수 없는 약속은 표시하지 않는다.
- 게시판 질문에서 계산기로 돌아갈 수 있게 안내한다. 관련성이 없는 전체 화면 팝업이나 가입 유도 배너를 추가하지 않는다.
- 외부 카페·동호회에는 해당 공간 운영자의 홍보 규칙과 허락을 확인한 뒤 도움 되는 자료로 소개하는 안을 준비한다. 자동 광고·대량 글쓰기·무단 연락은 하지 않는다.

### 4주차: 행동에 따라 개선

- 계산은 많은데 공유가 적으면 입력값 공개 안내·복사 실패·모바일 공유 동작을 점검한다.
- 초안 확인은 많은데 질문이 적으면 로그인 복귀, 편집기 초기화, 질문 제목/내용 유지부터 확인한다.
- 질문은 있는데 답변이 없으면 게시판을 더 늘리기보다 답변 가능한 주제와 운영 시간을 좁힌다.
- 동호회별 게시판은 실제 동호회 운영진이 가입·운영 흐름을 검수한 뒤 공개하는 계획으로 연결한다.

## 측정 기준

| 지표 | 목적 | 수집할 최소 정보 |
| --- | --- | --- |
| 도구 페이지 진입 | 검색/공유 진입 여부 | 경로와 날짜별 집계 |
| 계산 성공 / 검증 실패 | 입력 난이도 확인 | 도구명·이벤트 종류·오류 분류 |
| 결과 공유 시도 | 공유 동작 이용 여부 | 도구명·공유/복사/취소 종류 |
| 질문 초안 확인 / 글쓰기 진입 | 도구→커뮤니티 연결 | 이벤트 종류 |
| 질문 게시 완료 / 첫 답변 시간 | 실제 커뮤니티 가치 | 공개 게시글의 생성/답변 시각 집계 |

체중·가격·부츠 크기·이메일·회원 ID·초안 내용은 이벤트에 포함하지 않는다. 공유 시도는 외부에서 실제 공유가 완료됐다는 증거가 아니므로 별도 이름으로 집계해야 한다. 이번 도구에는 외부 분석 SDK나 자동 전송을 넣지 않았다. 운영 계측을 붙일 때는 보관 기간·접근 권한·분석 서비스 사용 여부를 개인정보 정책과 함께 확정해야 한다.
