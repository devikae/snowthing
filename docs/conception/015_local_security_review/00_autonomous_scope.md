# 승인된 자율 작업 범위와 현재 대조

기존 `docs/project/autonomous-work-20261101.md`는 저장소 ignore 규칙 때문에 변경 추적 대상에서 빠질 수 있어 승인 범위를 이 문서에도 남긴다. 범위를 줄이지 않는다.

사용자는 로컬에서 프로필 설정뿐 아니라 시즌권 본전 계산기, 성향별 데크 계산기, 초기 사용자 유입 기능, 동호회마다 쓰는 게시판, 라이브톡 챗봇/MCP 검토, 기존 코드 전반의 보안/정합성 점검과 필요한 보완을 자율 진행하도록 승인했다. 외부 게시·광고 집행·유료 API·운영 배포·운영 DB/S3 변경은 하지 않는다. 기존 변경과 사용자 데이터는 보존한다.

| 항목 | 확인된 결과 | 계속 대조할 사항 |
| --- | --- | --- |
| 내 정보 설정 | 실제 API/DB 조회·수정, 닉네임 확인, 사진 변경/복원, 비밀번호 변경, 프로필 메뉴, 테스트·브라우저 검증 | 최종 전체 회귀와 기존 변경 보존 |
| 시즌권 도구 | 부대비용 포함 비교, 방문/본전/목표, 공유 복원, 비로그인 사용 | 최종 전체 회귀 |
| 데크 도구 | 제조사 근거·체중/부츠/실력/성향·모델 체중 비교·공유·질문 초안 | 모델별 실측 대체가 아니라는 안내 유지 |
| 유입 | 공개 도구·결과 공유·로그인 후 질문 초안, 실행/측정 계획 | 실제 홍보/측정 전송은 실행하지 않음 |
| 동호회별 게시판 | 별도 동호회 글/댓글·가입 승인·역할·양도·폐쇄·마이그레이션·권한/경합 테스트·다중 회원 브라우저 | 추가 발견된 역할 변경 경계 수정·최종 회귀 |
| 챗봇/MCP | 기존 위임 허용 목록 검토, 장터 연락처 제거, 전체 답변 검사/전화번호, 전역 비용 시도 제한, 외부 호출 없는 도구 도움말 | 별도 MCP 저장소 및 timeout/로그 경계 추가 대조 |
| 전반적 보안 | 로그인 복귀 경로·프로필 권한/중복/경합·동호회 비공개 경계·업로드 해상도·봇 유출 경로 수정 | 가입 동의의 소셜 신규 경로, 업로드 동시성/일반 계정 제한, 서비스별 접근/입력·데이터 보존 범위, 운영 사실 미확정 문서 대조 |

모든 항목을 이미 완료한 것으로 취급하지 않는다. 개별 검증 문서와 테스트 결과를 현재 코드에 대조한 뒤 전체 완료 여부를 결정한다. 운영 처리방침의 보관·파기/수탁 현황 등은 코드만으로 확정하지 않는다.
