## 상세·폼 디자인 보완

사용자 추가 피드백으로 게시글·카풀·장터의 상세/작성/수정 9개 화면을 같은 content-compose-page/content-detail-page 범위로 정리했다. 폼 너비·제목·라벨·입력·버튼·첨부 UI와 댓글 본문을 공통 토큰에 맞췄다. 불필요한 회색 외곽 카드와 영어 장식을 덜고, 카풀 비용의 예전 파란 패널과 장터 편집기의 흰 다크 배경을 수정했다. 에디터 자동 포커스로 모바일 상단이 밀리는 것도 막았다. 추천 활성 표시는 실제 반응 상태를 따른다.

기존 localhost:3000 작업본에는 디자인 파일만 동기화했고 동호회 로컬 코드는 보존했다. PR용 작업본은 동호회 경로/메뉴/마이그레이션을 포함하지 않는다. 브라우저 디자인 검수는 읽기 전용 계약 fixture로 1440/390px·라이트/다크 36개 조합을 확인하며, 실제 로컬 API의 게시글·카풀 상세와 작성 폼도 별도로 확인했다. 저장·삭제 API나 외부 이미지 업로드를 디자인 검수에서 실행하지 않는다. 외부 웹캠 전체의 현재 재생을 이 검수로 보증하지 않는다.
