# 공지사항 게시판

## 요구사항

- 기존 게시글에 `NOTICE` 카테고리를 추가한다. 글 작성은 `ROLE_ADMIN`만 허용하며 익명 작성은 허용하지 않는다.
- 글 수정은 기존 작성자 본인 정책을 유지하고, 공지로 변경하거나 공지를 수정할 때에도 관리자 권한을 확인한다.
- 공지 조회는 공개하며 `NORMAL` 상태이고 삭제되지 않은 글만 조회한다. 최신순은 기존 게시글 목록의 ID 내림차순을 사용한다.
- 각 게시판 상단에는 최신 공지 최대 3개를 표시한다. 공지사항 목록 자체에서는 중복 표시하지 않는다.
- 기존 공지 예시 문구는 제거한다. 공지가 없으면 상단 공지 영역을 표시하지 않는다.

## 데이터와 API

- `post_category`에 코드 `NOTICE`를 추가하고 게시글·이미지·작성자 관계는 기존 구조를 재사용한다. 신규 N:M 관계는 없다.
- 공지 목록은 `GET /api/v1/posts?categoryCode=NOTICE&page=1&size=3`을 사용한다. 작성·수정은 기존 게시글 API를 사용하며 서버에서 관리자 권한을 검사한다.
- 운영 변경은 018 마이그레이션으로 추가한다. 이전 마이그레이션은 변경하지 않는다.

## 검증

- 관리자 작성 성공, 비회원·일반 회원 작성 거부, 일반 회원의 기존 글 공지 전환 거부를 검증한다.
- 삭제·숨김·차단 글 제외와 최신 정상 공지 최대 3개 조회를 검증한다.
- 클라이언트의 권한 표시와 서버의 권한 검사를 분리하고, 봇 위임 사용자에게 관리자 권한이 부여되지 않는 기존 정책을 유지한다.
