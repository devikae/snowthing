# Snowthing REST API 명세서 (REST API Specification)

## 1. 개요 (Overview)

Snowthing 플랫폼의 백엔드와 프론트엔드 간 통신을 위한 RESTful API 명세서입니다.
REST 자원 중심(Resource-Oriented) 명사형 URL 체계, 세션 기반 인증 (`JSESSIONID`), 비회원/익명 작성 지원, 게시글 상태 관리(`status`), 비동기 추천/비추천 처리, 계층형 댓글 DTO 파싱, 그리고 글로벌 에러 응답 규격을 적용하였습니다.

* **Base URL**: `/api/v1`
* **인증 방식**: Session Cookie (`JSESSIONID`, `HttpOnly`, `Secure`, `SameSite=Lax`)
* **데이터 포맷**: `application/json`
* **권한 체계**: `GUEST` (비회원), `ROLE_USER` (일반 회원), `ROLE_ADMIN` (최고 관리자)
* **게시글 상태 (`status`)**: `NORMAL` (정상), `HIDDEN` (관리자 숨김), `DELETED` (Soft Delete), `BLOCKED` (차단)

## 3. 회원 및 인증 API 상세 명세

### 3.1. 회원가입 (`POST /api/members`)
* **설명**: 신규 회원을 생성합니다.
* **Request Body**:
```json
{
  "email": "user@example.com",
  "password": "Password123!",
  "nickname": "신나는보더",
  "departureRegion": "서울 송파구",
  "bio": "주말마다 휘팍 가는 카빙 보더입니다.",
  "resortIds": [1, 2],
  "ridingStyleIds": [1, 3]
}
```
* **Response Body (201 Created)**:
```json
{
  "publicId": "a3b2c1d4-5e6f-7a8b-9c0d-1e2f3a4b5c6d",
  "email": "user@example.com",
  "nickname": "신나는보더",
  "createdAt": "2026-08-08T10:00:00"
}
```

### 3.2. 세션 로그인 (`POST /api/auth/login`)
* **설명**: 회원 인증 후 세션 쿠키(`JSESSIONID`)를 발급합니다.
* **Request Header**: `Idempotency-Key` (선택적)
* **Response Header**: `Set-Cookie: JSESSIONID=...; Path=/api; HttpOnly; Secure; SameSite=Lax`
* **Response Body (200 OK)**:
```json
{
  "publicId": "a3b2c1d4-5e6f-7a8b-9c0d-1e2f3a4b5c6d",
  "nickname": "신나는보더",
  "role": "ROLE_USER"
}
```

### 3.3. 내 프로필 수정 (`PUT /api/members/me`)
* **설명**: 내 프로필 정보 및 베이스 스키장/라이딩 스타일 중계 테이블 관계를 업데이트합니다.
* **Request Body**:
```json
{
  "nickname": "휘팍카빙마스터",
  "bio": "카빙 연습 중입니다!",
  "departureRegion": "경기 성남시",
  "resortIds": [1],
  "ridingStyleIds": [1, 2]
}
```

## 4. 게시글 API 상세 명세

### 4.1. 게시글 작성 (`POST /api/posts`)
* **설명**: 게시글을 작성합니다. (회원 작성 및 비회원 익명 작성 모두 지원)
* **Request Body (회원 작성 시)**:
```json
{
  "categoryCode": "FREE",
  "title": "주말 휘팍 설질 어떤가요?",
  "content": "내일 아침에 출발하려는데 설질 괜찮은지 궁금합니다.",
  "isAnonymous": false,
  "imageUrls": [
    "https://cdn.snowthing.com/images/1.jpg"
  ]
}
```
* **Request Body (비회원 익명 작성 시)**:
```json
{
  "categoryCode": "ANONYMOUS",
  "title": "익명 질문입니다.",
  "content": "입문용 데크 추천 부탁드립니다.",
  "isAnonymous": true,
  "anonymousPassword": "AnonPassword123!"
}
```
* **Response Body (201 Created)**:
```json
{
  "publicId": "p9o8i7u6-5y4t-3r2e-1w0q-9a8b7c6d5e4f",
  "title": "주말 휘팍 설질 어떤가요?",
  "writerName": "익명 (123.456.***.***)",
  "status": "NORMAL",
  "createdAt": "2026-08-08T10:15:00"
}
```

### 4.2. 게시글 상세 조회 (`GET /api/posts/{publicId}`)
* **설명**: 게시글 상세 정보를 조회합니다. 일반 유저는 `NORMAL` 상태인 글만 조회 가능하며, `HIDDEN`/`BLOCKED` 글 조회 시 `404 Not Found` 또는 `403 Forbidden`을 반환합니다. (관리자는 모든 상태 조회 가능)
* **Response Body (200 OK)**:
```json
{
  "publicId": "p9o8i7u6-5y4t-3r2e-1w0q-9a8b7c6d5e4f",
  "categoryName": "자유게시판",
  "title": "주말 휘팍 설질 어떤가요?",
  "content": "내일 아침에 출발하려는데 설질 괜찮은지 궁금합니다.",
  "status": "NORMAL",
  "viewCount": 42,
  "commentCount": 2,
  "likeCount": 12,
  "dislikeCount": 1,
  "writer": {
    "publicId": "a3b2c1d4-5e6f-7a8b-9c0d-1e2f3a4b5c6d",
    "nickname": "신나는보더",
    "profileImageUrl": "https://cdn.snowthing.com/profiles/1.jpg"
  },
  "images": [
    "https://cdn.snowthing.com/images/1.jpg"
  ],
  "createdAt": "2026-08-08T10:15:00"
}
```

### 4.3. 게시글 추천/비추천 투표 (`POST /api/posts/{publicId}/reactions`)
* **설명**: 게시글에 추천(`LIKE`) 또는 비추천(`DISLIKE`)을 투표합니다. (백엔드 `@Async` 비동기 이벤트 적용)
* **Request Body**:
```json
{
  "type": "LIKE"
}
```

## 5. 댓글 및 대댓글 계층형 API 상세 명세

### 5.1. 댓글/대댓글 계층형 목록 조회 (`GET /api/posts/{publicId}/comments`)
* **설명**: 게시글의 모든 댓글을 `Single Query`로 가져와 자바 메모리에서 부모-자식 트리 구조(`children: []`)로 재조립하여 반환합니다.
* **Response Body (200 OK)**:
```json
{
  "postId": "p9o8i7u6-5y4t-3r2e-1w0q-9a8b7c6d5e4f",
  "totalCommentCount": 3,
  "comments": [
    {
      "commentId": 101,
      "parentId": null,
      "writerName": "신나는보더",
      "content": "휘팍 오늘 팽팽하고 설질 최고입니다!",
      "isDeleted": false,
      "createdAt": "2026-08-08T10:20:00",
      "children": [
        {
          "commentId": 102,
          "parentId": 101,
          "writerName": "익명 (211.200.***.***)",
          "content": "오! 야간에도 슬로프 열려있나요?",
          "isDeleted": false,
          "createdAt": "2026-08-08T10:22:00",
          "children": []
        }
      ]
    },
    {
      "commentId": 103,
      "parentId": null,
      "writerName": "익명 (112.150.***.***)",
      "content": "삭제된 댓글입니다.",
      "isDeleted": true,
      "createdAt": "2026-08-08T10:25:00",
      "children": []
    }
  ]
}
```

### 5.2. 댓글/대댓글 작성 (`POST /api/posts/{publicId}/comments`)
* **설명**: 원댓글 또는 대댓글을 작성합니다. (대댓글 작성 시 `parentId` 지정, 비회원 작성 시 `anonymousPassword` 필수)
* **Request Body (비회원 대댓글 작성 시)**:
```json
{
  "parentId": 101,
  "content": "야간에도 정설 잘 되어 있습니다!",
  "isAnonymous": true,
  "anonymousPassword": "AnonComment123!"
}
```
* **Response Body (201 Created)**:
```json
{
  "commentId": 104,
  "parentId": 101,
  "writerName": "익명 (211.200.***.***)",
  "content": "야간에도 정설 잘 되어 있습니다!",
  "createdAt": "2026-08-08T10:30:00"
}
```

### 5.3. 댓글 삭제 (`DELETE /api/comments/{commentId}`)
* **설명**: 댓글을 Soft Delete (`is_deleted = true`) 처리합니다. 비회원 댓글 삭제 시 `anonymousPassword`를 쿼리 파라미터 또는 Body로 전달합니다.
* **Request Body (비회원 삭제 시)**:
```json
{
  "anonymousPassword": "AnonComment123!"
}
```
* **Response Body (200 OK)**:
```json
{
  "message": "댓글이 정상적으로 삭제(Soft Delete) 처리되었습니다.",
  "commentId": 104
}
```

## 6. 실패 응답 규격 (Global Error Response Standard)

모든 API 에러 응답은 일관된 JSON 스키마 구조로 반환됩니다.

### 6.1. 에러 응답 JSON 포맷 (Error Response JSON)
```json
{
  "timestamp": "2026-08-08T10:20:00",
  "status": 400,
  "code": "INVALID_INPUT_VALUE",
  "message": "입력값이 유효하지 않습니다.",
  "errors": [
    {
      "field": "email",
      "value": "invalid-email-format",
      "reason": "올바른 이메일 형식이 아닙니다."
    }
  ]
}
```

### 6.2. HTTP Status Code 별 에러 코드 명세

| Status | Error Code | 설명 및 발생 조건 |
| :--- | :--- | :--- |
| **`400 Bad Request`** | `INVALID_INPUT_VALUE` | DTO 유효성 검사 실패 (이메일 형식, 비밀번호 길이 등) |
| | `DUPLICATE_EMAIL` | 이미 존재하는 이메일로 가입 시도 |
| | `DUPLICATE_NICKNAME` | 이미 존재하는 닉네임으로 가입/수정 시도 |
| **`401 Unauthorized`** | `UNAUTHORIZED` | 비로그인 유저가 회원 전용 API 호출 |
| | `INVALID_CREDENTIALS` | 로그인 시 이메일 또는 비밀번호 불일치 |
| **`403 Forbidden`** | `ACCESS_DENIED` | 타인의 글/댓글 수정·삭제 시도 권한 없음 |
| | `INVALID_ANON_PASSWORD` | 비회원 글/댓글 수정·삭제 시 비밀번호 불일치 |
| **`404 Not Found`** | `RESOURCE_NOT_FOUND` | 존재하지 않거나 숨김/삭제 처리된 게시글/댓글/회원 조회 |
| **`409 Conflict`** | `ALREADY_REACTED` | 해당 게시글에 이미 추천/비추천 투표를 마친 경우 |
| **`500 Internal Error`**| `INTERNAL_SERVER_ERROR` | 서버 내부 비즈니스 로직 예외 발생 |
