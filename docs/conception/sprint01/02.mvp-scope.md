# MVP 개발 범위 및 사용자 시나리오 (MVP Scope & User Scenario)

## 1. MVP 개발 범위 정의 (MVP Scope)

### 1.1. 1차 MVP 포함 기능 (In-Scope)
Snowthing의 최소 기능 제품(MVP) 단계에서 안정적으로 작동하도록 구현할 6가지 핵심 기능입니다.

* **인증 및 회원 관리 (Authentication)**
  * 회원가입 (이메일, 비밀번호, 닉네임, 중복 검증)
  * 세션(Session) 기반 로그인/로그아웃 (`JSESSIONID`, `changeSessionId()` 세션 고정 방어, 6대 보안 쿠키)
  * 권한 체계 (`GUEST` 비회원, `ROLE_USER` 회원, `ROLE_ADMIN` 관리자)
* **보더 프로필 기능 (Profile)**
  * 프로필 상세 조회 및 수정 (자기소개 `bio`, 주 출발지 `departureRegion`)
  * N:M 베이스 스키장 (`member_resort`) 및 라이딩 성향 (`member_riding_style`) 중계 테이블 관리 (단일 대리키 `id` PK)
* **게시판 기능 (Board CRUD)**
  * 게시글 작성, 카테고리별 목록 조회(페이징), 상세 조회(조회수 +1), 수정, 삭제
  * **게시글 상태 관리 (`status`)**: `NORMAL`(정상), `HIDDEN`(관리자 숨김), `DELETED`(유저 삭제), `BLOCKED`(차단)
* **비회원 & 익명 작성 기능 (Anonymous Support)**
  * 회원 비익명 작성 / 회원 익명 작성 / **비회원 익명 작성** 모두 지원
  * `member_id` NULLABLE, 작성자 IP (`writer_ip`), 비회원 비밀번호 (`anonymous_password` BCrypt)
  * 익명 작성 시 닉네임 대신 **`익명 (IP 마스킹)`** 렌더링 규칙
* **게시글 이미지 & 비동기 추천 기능 (Image & Async Reaction)**
  * 게시글 이미지 1:N 업로드 (`post_image`)
  * 게시글 추천/비추천 (`post_reaction`) **`@Async` 비동기 이벤트** 처리 및 중복 투표 방지 (`UNIQUE`)
* **댓글 및 계층형 대댓글 기능 (Comment Hierarchy)**
  * 게시글별 댓글 작성 및 삭제 (Soft Delete ➔ "삭제된 댓글입니다")
  * **`Single Query + In-Memory Tree` 댓글 계층형 조립**: `WHERE post_id = :postId` 단 1번의 JPQL DTO 직조회 + 자바 `HashMap` 포인터 파싱

### 1.2. 차후 확장 기능 (Out-of-Scope / Roadmap)
1차 MVP 구현 및 안정화 이후 단계적으로 추가될 확장 기능 범위입니다.

* **Phase 2 (현장 정보 및 AI 기능)**
  * 스키장별 통합 웹캠 조회 및 AI 기반 혼잡도 판단
  * AI 게시판 흐름 3줄 요약
  * 장비 VS 투표 및 랭킹 시스템
* **Phase 3 (소셜 & 동호회 크루 기능)**
  * **동호회/크루 시스템 (`crew`)**: 1차 MVP에서는 제외(Out-of-Scope). `member.crew_id` FK는 NULLABLE로 보존하되 Phase 3에서 크루 생성/가입/관리 구축.
  * N분의 1 카풀 정산 자동 계산기 및 카풀 모집 연동
  * 보더명함 프로필 기반 1:1 같이타요 매칭 및 쪽지/채팅
* **인증/인가 아키텍처 확장 (Architecture Extension)**
  * **OAuth2 소셜 로그인 연동**: 카카오/구글/네이버 소셜 가입 지원 (`password NULLABLE`)
