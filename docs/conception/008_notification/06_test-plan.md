# 인앱 알림 테스트 계획

## 1. 댓글 생성 규칙

- 회원 게시글에 다른 회원이 루트 댓글 작성 → 게시글 작성자 알림 1건
- 회원 익명 게시글에 댓글 작성 → 실제 게시글 작성 회원 알림 1건
- 비회원 익명 게시글에 댓글 작성 → 알림 0건
- 본인 게시글에 본인이 댓글 작성 → 알림 0건
- 비회원 익명 댓글이 회원 게시글에 작성됨 → 게시글 작성자 알림 1건, 작성자 정보 미노출
- 중고장터 댓글 작성 → 1차 알림 0건

## 2. 대댓글 생성 규칙

- 다른 회원이 회원 루트 댓글에 대댓글 작성 → 루트 댓글 작성자 알림 1건
- 대댓글 작성 시 게시글 작성자 알림 0건
- 여러 사용자가 같은 루트 아래에서 대댓글 작성 → 각 대댓글마다 루트 작성자에게만 알림
- 다른 대댓글에 답하는 UI 동작도 저장된 루트 댓글 작성자에게만 알림
- 비회원 루트 댓글에 대댓글 작성 → 알림 0건
- 본인 루트 댓글에 본인이 대댓글 작성 → 알림 0건
- 게시글 작성자와 루트 댓글 작성자가 같은 경우 → 자기 대댓글이면 0건, 다른 회원 대댓글이면 루트 댓글 알림 1건

## 3. 베스트 규칙

- 추천 수 29에서 유효한 LIKE 생성으로 30 도달 → `POST_BEST` 1건
- 중복 PUT으로 카운트가 변하지 않음 → 추가 알림 0건
- 30에서 추천 취소 후 다시 30 도달 → 추가 알림 0건
- 30을 넘은 상태의 추천 → 추가 알림 0건
- 비회원 익명 게시글이 30 도달 → 알림 0건
- 게시글 작성자 본인의 추천으로 30 도달 → 알림 0건
- 동시 추천으로 임계값을 통과해도 베스트 알림은 정확히 1건

## 4. 트랜잭션과 멱등성

- 알림 INSERT 실패 → 댓글·댓글 수 증가 전체 롤백
- 댓글 저장 실패 → 알림 미생성
- 같은 생성 사건 재처리 → UNIQUE 멱등 키로 알림 1건 유지
- 추천 row나 카운터 변경 실패 → 베스트 알림 미생성
- 원본 커밋과 알림 커밋이 서로 다른 상태로 남지 않음

## 5. API와 권한

- 비로그인 목록·미읽음·읽음 API → 401
- A 회원 목록에는 A의 알림만 반환
- A가 B의 알림 읽음 요청 → 404와 상태 불변
- 한 건 읽음 재호출 → 204와 동일한 `readAt` 유지
- 전체 읽음 → 현재 회원의 미읽음만 변경
- 잘못된 크기·커서 → 타입 기반 ErrorCode 응답
- 목록 정렬과 다음 커서에 중복·누락 없음
- 응답 DTO 컬렉션은 방어적으로 복사됨

## 6. 원본 상태와 개인정보

- 정상 게시글 → 제목과 이동 경로 반환
- 삭제·숨김·차단 게시글 → `targetAvailable=false`, 제목 미노출
- 삭제된 댓글 알림 → 댓글 본문 미노출, 공개 게시글 이동 가능
- 회원 익명·비회원 익명 댓글 → 실제 작성자 ID·닉네임·IP 미노출

## 7. 보관 작업

- 읽은 지 30일 기준이 아니라 생성 후 30일이 지난 읽은 알림 삭제
- 생성 후 90일이 지난 미읽음 알림 삭제
- 경계 시각 이전·이후 행을 정확히 구분
- 제한된 배치 크기로 반복 삭제
- 같은 정리 작업 재실행이 안전함

## 8. 프런트엔드

- 비로그인 상태에서 종 아이콘 없음
- 로그인 상태에서 종 아이콘과 미읽음 배지 표시
- 100건 이상은 `99+` 표시
- 알림 열기 전에는 목록 API를 요청하지 않음
- 비활성 탭에서 폴링 중단, 복귀 시 즉시 갱신
- 알림 선택 시 읽음 처리 후 공개 가능한 게시글로 이동
- 이동 불가능한 알림은 안내하고 현재 화면 유지
- 모두 읽음 후 배지와 목록 상태 동기화
- 키보드 탐색, 포커스 이동, `aria-expanded`, 상태 문구 검증

## 9. 회귀 검증

- 기존 댓글 생성·수정·삭제와 댓글 카운트 테스트
- 댓글 루트 커서·대댓글 Top-5 조회 테스트
- 추천 PUT/DELETE 동시성·정합성 테스트
- 일반 게시판·익명 게시판·카풀·중고장터 접근 정책 테스트
- 백엔드 전체 테스트, Spotless, 프런트엔드 lint와 production build
- MySQL 016 마이그레이션과 인덱스·제약 검증
