# 인앱 알림 설계 문서

## 결정 요약

- 1차 범위는 이메일·브라우저 푸시가 아닌 로그인 회원용 인앱 알림이다.
- 내 게시글의 루트 댓글, 내 루트 댓글의 대댓글, 내 게시글의 베스트 최초 진입을 알린다.
- 대댓글은 루트 댓글 작성자에게만 알린다. 게시글 작성자와 다른 대댓글 작성자에게는 보내지 않는다.
- 자기 행동으로 자기 자신에게 알림을 만들지 않는다.
- 회원 익명 게시글은 실제 회원 소유자를 수신자로 사용하되 화면에서 신원을 노출하지 않는다.
- 비회원 익명 게시글과 비회원 익명 댓글은 회원 수신자가 없을 때 알림을 만들지 않는다.
- 알림은 원본 변경과 같은 MySQL 트랜잭션에서 저장하고, 조회는 REST API와 30초 폴링으로 시작한다.
- 실시간 전송이 필요해지면 저장 구조를 유지한 채 SSE를 추가한다.
