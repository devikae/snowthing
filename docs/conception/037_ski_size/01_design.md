# 스키 사이즈 계산기 (2026-11-24)

## 배경

라이더 도구에 데크 사이즈 계산기만 있어 스키 이용자는 길이를 확인할 곳이 없었다. 사용자가 카빙(회전), 대회전 같은 용도와 키, 체중으로 스키 길이를 정하는 계산기를 요청했다.

## 범위

- `/tools/ski-size` 공개 경로, 도구 목록 카드, 사이트맵.
- 비로그인 프론트 계산이다. DB, API, 저장이 없다.
- 화면은 데크 계산기와 같은 카드 구성(`docs/specs/rider-tools-card-ui.md`)을 쓴다.

## 결정

| 질문 | 고른 안 | 고르지 않은 안과 이유 |
|---|---|---|
| 회전, 대회전을 어떻게 다루나 | A. 제조사 표 범위를 Short, Mid, Long으로 나누고 회전, 대회전은 줄의 용도 문구로 안내 | B. 종류를 먼저 골라 종류별 길이: 일반인용 공식 표가 없어 기준을 지어내야 한다. C. FIS 대회 최소 길이 병기: 선수 규정이라 일반 이용자에게 길게 읽힌다 |
| 입력 | 키, 체중 | 실력 입력 추가: 입력이 늘고, 데크 계산기에서 실력 입력을 뺀 결정과 어긋난다 |
| 체중을 어떻게 쓰나 | A. BMI로 키 대비 체격을 판단해 먼저 볼 줄만 강조 | B. 표시만: 체중을 받는 의미가 거의 없다 |

## 근거 자료

- Nordica 공식 스키 사이즈 안내 (성인): https://www.nordica.com/assets/downloads/ski-sizer_en.pdf (2026-11-24 확인, PDF 수정일 2024-11-06)
- 표 글자가 특수 폰트라 텍스트로 해독한 값을 PDF를 그림으로 열어 14줄 모두 대조했다.

| 키(cm) | 길이(cm) | 키(cm) | 길이(cm) |
|---|---|---|---|
| 122 | 100~110 | 158 | 145~165 |
| 127 | 110~120 | 163 | 150~170 |
| 132 | 120~130 | 168 | 155~175 |
| 137 | 125~135 | 173 | 160~180 |
| 142 | 130~140 | 178 | 165~185 |
| 147 | 135~145 | 183 | 170~185 |
| 152 | 140~155 | 188 이상 | 175~193 |

- 같은 자료의 선택 기준. 짧게: 초중급, 짧고 빠른 턴, 카빙 스키, 키에 비해 가벼움. 길게: 상급, 빠른 속도와 긴 턴, 비정설 사면, 로커가 많은 스키, 키에 비해 무거움.

## 계산 규칙 (`frontend/app/lib/skiSize.ts`)

- 입력: 키 122~210cm 정수, 체중 30~200kg(소수 첫째 자리). 122cm 미만(어린이 표)은 받지 않는다.
- 키에 가장 가까운 표의 줄을 쓴다. 두 줄의 한가운데면 짧은 쪽 줄을 쓴다. 188cm 이상은 마지막 줄.
- Short, Mid, Long은 데크와 같은 `deckLengthBands`로 범위를 나눈다(양 끝 각 4분의 1, 가운데 나머지). 제조사 구간이 아니라 표시 규칙이다.
- 체격: BMI를 소수 첫째 자리로 반올림한 값으로 판단한다. 18.5 미만은 가벼움(Short 강조), 25 이상은 무거움(Long 강조, 대한비만학회 비만 기준), 그 사이는 Mid 강조. 화면에 보이는 BMI와 판단이 어긋나지 않게 반올림한 값을 쓴다. 체중은 길이 숫자를 바꾸지 않는다.
- 공유: URL fragment `#height=178&weight=75`. 형식이 틀리거나 범위 밖이면 복원하지 않고 직접 입력을 안내한다.

## 하지 않는 것

- 어린이 표, 실력 입력, 종류 선택, FIS 대회 규정 표시.
- 질문 초안 만들기, 모델별 권장값 비교 (데크 계산기에는 있다. 필요해지면 후속으로 검토한다).
- 체중으로 길이 숫자를 보정하는 것. 자료에 숫자 기준이 없다.

## 검증

- 계산 함수 경계값: 키 121, 122, 155(줄 사이 동률), 188, 210, 211, 소수 키, 체중 29.9, 200.1, BMI 18.5와 25 경계, 공유 문자열 누락, 중복, 범위 밖, 지수 표기.
- 화면: 모바일 라이트, 다크, 도구 목록 카드.
