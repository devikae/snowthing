# 카풀 테스트 계획

## 1. 도메인·검증

- 편도는 `returnAt`을 받지 않음
- 왕복은 복귀 시각이 출발 이후인지 검증
- 인원·연비·거리는 양수, 통행료는 0 이상
- 카풀 게시글과 상세 1:1 생성·수정·삭제
- 일반 게시글에 카풀 상세가 붙지 않음
- 운전자 포함 인원으로 비용 계산

## 2. API·권한

- 비회원의 생성·수정·삭제가 401/403으로 차단됨
- 작성자 외 수정·삭제 차단
- 관리자 수정·삭제 허용과 삭제 후 상세 조회 차단
- 비회원 공개 동의에 따른 연락처 응답 차이
- 연락처 미입력과 긴 입력값 검증
- 댓글은 기존 로그인 정책으로 작성 가능
- 장비 적재 가능 여부가 생성·목록·상세 응답에 동일하게 반영됨
- 일반 상세 응답은 출발 좌표를 숨기고 작성자·관리자 응답만 수정용 좌표를 포함함

## 3. 외부 API

- 오피넷 정상 응답이 연료 종류·유가·조회 시각에 반영됨
- 오피넷 timeout/5xx 시 생성이 부분 저장되지 않고 명확한 오류를 반환함
- 카카오 경로 정상 응답이 거리·통행료에 반영됨
- 경로 목적지가 카카오 장소 검색 결과 순위와 무관하게 DB의 리조트 기준 좌표를 사용함
- 경로 API 실패 시 게시글 데이터가 부분 저장되지 않음
- 외부 API 키가 응답·로그에 노출되지 않음
- 캐시가 같은 조건의 반복 호출을 줄임
- 장소 검색 분당 30회, 비용 미리보기·등록·수정 합산 분당 12회 초과 요청 차단
- 오피넷 최초 응답은 `OPINET`, 같은 유종의 유효 캐시는 `CACHE`로 구분
- 오피넷·캐시 실패 후 1,000원과 3,000원 경계 유가 허용, 범위 밖 거부
- 카카오 수동 경로의 1~2,000km 거리와 0~20,000원 통행료 경계값 검증
- 수동 경로에서는 카카오 길찾기를 호출하지 않고 서버가 비용을 계산함

## 4. 비용 계산

- 편도 경로 계산과 출발·복귀 경로가 서로 다른 왕복 합산 계산
- 연료비·통행료·총액 계산
- 운전자 포함 분모 계산
- 반올림 규칙 고정
- `MANUAL` 모드에서는 거리·통행료·유가 스냅샷을 유지하면서 입력한 1인 금액이 저장됨

## 5. 통합·브라우저

- 카풀 목록·상세·작성·수정 화면
- 댓글·대댓글 목록, 추가 조회, 작성, 수정, 삭제 연결
- 목록 20건·최대 5개 페이지 번호 표시와 메인·게시판 사이드바 최신 4건 실제 데이터 연결
- 지난 출발 일정 제외와 목록 DTO의 본문·연락처 미포함 확인
- 목록은 최신 등록순을 유지하고 100페이지를 넘는 요청은 저장소 조회 전에 차단
- 비로그인 작성 화면의 회원가입·로그인 유도
- 모바일 입력과 날짜 시간대 처리
- 연락처 공개 동의 전후 비회원 상세 비교
- 외부 오픈카톡 링크·전화 링크 표시
- `010` 마이그레이션의 복합 인덱스 컬럼 순서와 13개 리조트 좌표 입력 검증
- `011` 마이그레이션의 유가 출처와 기존 카풀 목적지 좌표 백필 검증
- `012` 마이그레이션의 `created_at DESC, post_id DESC` 최신순 정렬 인덱스 검증
- 운영 규모 데이터에서는 목록 쿼리를 `EXPLAIN ANALYZE`해 스캔 행 수와 filesort 여부 기록
