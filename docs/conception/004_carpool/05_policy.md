## 2. 연락처

- 카카오톡 ID·링크·전화번호 등 자유 입력
- 입력하지 않아도 게시글 등록 가능
- `contactPublicToGuest`는 기본값 `false`
- 비회원 공개를 선택할 때 개인정보 노출 경고와 동의를 받음
- 동의한 경우 비회원 상세 응답에도 표시
- 동의하지 않은 경우 작성자 본인을 포함한 다른 사용자에게 표시하지 않음
- 게시글 삭제 시 서비스 화면에서 즉시 숨김
- 공개된 연락처의 외부 복사·캡처·재배포는 회수할 수 없음을 안내

## 3. 위치

집이나 현재 위치를 요구하지 않고 공개 가능한 집결지를 입력합니다. 좌표는 경로 계산에만 사용하며, 상세 응답에서는 작성자가 입력한 집결지 표시명만 반환합니다.

## 4. 오피넷

서버가 연료 종류에 맞는 유가를 조회하고, 유가와 조회 시각을 저장합니다. 동일 연료·지역의 짧은 캐시를 사용해 API 호출량을 줄입니다. 응답 실패 시 저장된 기존 스냅샷은 유지하고, 신규 등록은 수동 유가 입력 또는 재시도를 허용합니다.

## 5. 카카오모빌리티

서버가 집결지 좌표와 리조트 좌표로 자동차 경로를 요청합니다. 응답의 거리·통행료를 기본값으로 제시하되 작성자가 수정할 수 있습니다. API 키는 환경변수로 주입하고 요청 빈도·타임아웃·실패 로그를 관리합니다.

## 6. 계산 책임

표시 금액은 예상치입니다. 교통 상황, 우회, 실제 연비, 유가 변동, 추가 통행료가 반영되지 않을 수 있으며 SnowThing은 실제 정산을 보증하지 않습니다.
