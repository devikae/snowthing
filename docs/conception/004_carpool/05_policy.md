## 2. 연락처

- 카카오톡 ID·링크·전화번호 등 자유 입력
- 입력하지 않아도 게시글 등록 가능
- `contactPublicToGuest`는 기본값 `false`
- 비회원 공개를 선택할 때 개인정보 노출 경고와 동의를 받음
- 동의한 경우 비회원 상세 응답에도 표시
- 동의하지 않은 경우 작성자·관리자에게만 표시하고 다른 회원·비회원에게는 표시하지 않음
- 게시글 삭제 시 서비스 화면에서 즉시 숨김
- 공개된 연락처의 외부 복사·캡처·재배포는 회수할 수 없음을 안내

## 3. 위치

집이나 현재 위치를 요구하지 않고 공개 가능한 집결지를 입력합니다. 출발 좌표는 경로 계산과 작성자·관리자의 수정 화면에만 사용합니다. 일반 상세 응답은 좌표를 `null`로 반환하고 작성자가 입력한 집결지 표시명만 공개합니다.

## 4. 오피넷

서버는 유효한 6시간 오피넷 캐시를 먼저 사용하고, 캐시가 없으면 오피넷에서 전국 평균 유가를 조회합니다. 두 경로가 모두 불가능하면 사용자에게 1,000~3,000원/L 범위의 유가 입력을 요청합니다. 적용 출처를 `OPINET`, `CACHE`, `USER_INPUT`으로 저장하고 상세 화면에 표시합니다. 브라우저가 계산한 총액은 받지 않고 서버가 비용을 다시 계산합니다.

## 5. 카카오모빌리티

서버가 집결지 좌표와 리조트 마스터에 저장된 검증 좌표로 자동차 경로를 요청합니다. 리조트 명칭을 매 요청마다 검색하거나 검색 1위 결과를 자동 선택하지 않습니다. 카카오 지도·장소·길찾기 장애가 감지되면 UI가 수동 모드로 전환되어 출발 지역·집결지·총거리 1~2,000km·총 통행료 0~20,000원을 받습니다. 자동 경로는 `KAKAO`, 수동 경로는 `MANUAL`로 저장하고 상세 화면에 표시합니다. 수동 모드는 예상 정보이므로 서버가 외부 장애 발생 자체를 보안 토큰으로 증명하지는 않으며, 입력 범위·출처 표시·서버 재계산으로 오용 영향을 제한합니다.

## 6. 계산 책임

표시 금액은 예상치입니다. 교통 상황, 우회, 실제 연비, 유가 변동, 추가 통행료가 반영되지 않을 수 있으며 SnowThing은 실제 정산을 보증하지 않습니다.
