## 확정 범위

- 로그인 회원의 카풀 모집글 작성·수정·삭제
- 기존 `Post`와 `CarpoolDetail` 1:1 확장
- 카풀 전용 입력 템플릿과 기존 댓글 재사용
- 카카오모빌리티 경로 조회와 오피넷 유가 조회
- DB에 검증된 리조트별 스키장 진입 좌표를 보관하고 경로 목적지로 사용
- 오피넷 장애 시 유효 캐시, 이후 1,000~3,000원/L 사용자 입력 유가로 단계적 복구
- 카카오 지도·길찾기 장애 시 출발지·총거리·0~20,000원 통행료 수동 입력 지원
- 유가·거리·통행료·계산 시각의 스냅샷 저장
- 모집자가 선택한 경우 비회원에게도 연락처 공개
- 목록은 미래 출발 일정만 최신 등록순으로 최대 100페이지까지 조회하고 검색·정렬용 인덱스를 각각 둠

## 제외 범위

- 탑승 신청·승인·거절·좌석 예약
- 자동 매칭과 일정 충돌 검사
- 서비스 내부 메신저·푸시 알림
- 결제와 실제 비용 정산
