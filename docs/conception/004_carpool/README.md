## 확정 범위

- 로그인 회원의 카풀 모집글 작성·수정·삭제
- 기존 `Post`와 `CarpoolDetail` 1:1 확장
- 카풀 전용 입력 템플릿과 기존 댓글 재사용
- 카카오모빌리티 경로 조회와 오피넷 유가 조회
- 유가·거리·통행료·계산 시각의 스냅샷 저장
- 모집자가 선택한 경우 비회원에게도 연락처 공개

## 제외 범위

- 탑승 신청·승인·거절·좌석 예약
- 자동 매칭과 일정 충돌 검사
- 서비스 내부 메신저·푸시 알림
- 결제와 실제 비용 정산
