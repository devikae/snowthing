# 카풀 모집글 요구사항

## 1. 목적

오픈카톡에서 진행되는 카풀 모집을 대체하지 않고, 출발지·리조트·일정·예상 비용을 정리한 게시글을 검색하고 댓글로 협의할 수 있게 합니다.

## 2. 사용자 시나리오

1. 로그인 회원이 카풀 모집글 작성 화면에 진입합니다.
2. 출발 지역·집결지와 도착 리조트, 일정, 차량 정보를 입력합니다.
3. 경로 API와 오피넷 유가로 예상 비용을 계산합니다.
4. 작성자가 자동 계산된 거리·통행료를 확인하거나 수정합니다.
5. 게시글을 등록하고 로그인 사용자 댓글로 세부 내용을 협의합니다.
6. 작성자가 선택한 경우 연락처를 비회원에게도 공개합니다.

## 3. 기능 요구사항

| ID | 요구사항 |
|---|---|
| CP-F-001 | 카풀 모집글 작성은 로그인 회원만 가능해야 합니다. |
| CP-F-002 | 카풀은 기존 게시글의 `CARPOOL` 카테고리와 `CarpoolDetail`을 함께 생성해야 합니다. |
| CP-F-003 | 출발 지역·집결지·도착 리조트·출발 일시를 필수 입력합니다. |
| CP-F-004 | 편도·왕복을 선택하고 왕복이면 복귀 예정 일시를 입력합니다. |
| CP-F-005 | 모집 인원은 운전자를 제외한 양의 정수로 입력합니다. |
| CP-F-006 | 연료 종류·연비·경로·통행료를 사용해 예상 금액을 계산합니다. |
| CP-F-007 | 계산에 사용한 유가와 조회 시각을 저장합니다. |
| CP-F-008 | 자동 계산 실패 시 작성자가 거리·통행료를 직접 입력해 등록할 수 있어야 합니다. |
| CP-F-009 | 기존 게시글 댓글 API를 통해 로그인 회원만 댓글을 작성합니다. |
| CP-F-010 | 연락처는 선택 입력이며, 작성자가 동의한 경우에만 비회원에게 공개합니다. |
| CP-F-011 | 카풀 목록은 기존 게시글 페이징·검색 구조를 재사용합니다. |

## 4. 비기능 요구사항

- 외부 API 키는 서버에만 보관하며 브라우저에 노출하지 않습니다.
- 외부 API 결과와 실패를 서비스 장애로 전파하지 않습니다.
- 계산 결과는 게시글에 저장된 스냅샷을 기준으로 재현할 수 있어야 합니다.
- 연락처 공개 여부와 연락처 값은 작성자만 수정할 수 있습니다.
- 카풀 상세 정보가 없는 `CARPOOL` 게시글은 저장할 수 없습니다.
- DTO 컬렉션은 방어적 복사를 적용합니다.
- 예외는 `ErrorCode`와 커스텀 예외로 처리합니다.
- 서비스 레이어는 웹 세션을 직접 조작하지 않습니다.

## 5. 제외 범위

신청·승인·좌석 확정·일정 충돌 방지·실시간 채팅·결제는 이번 기능의 성공 조건에 포함하지 않습니다.

## 6. 완료 조건

- 로그인 회원이 카풀 모집글을 등록하고 목록·상세에서 조회할 수 있습니다.
- 기존 댓글이 카풀 게시글에서도 동작합니다.
- 자동 계산과 수동 보정 결과가 저장되고 다시 조회됩니다.
- 연락처 비회원 공개 선택이 실제 접근 권한과 일치합니다.
- 오피넷·경로 API 장애 시 수동 입력 fallback이 동작합니다.
