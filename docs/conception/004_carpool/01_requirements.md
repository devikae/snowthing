# 카풀 모집글 요구사항

## 1. 목적

오픈카톡에서 진행되는 카풀 모집을 대체하지 않고, 출발지·리조트·일정·예상 비용을 정리한 게시글을 검색하고 댓글로 협의할 수 있게 합니다.

## 2. 사용자 시나리오

1. 로그인 회원이 카풀 모집글 작성 화면에 진입합니다.
2. 출발 지역·집결지와 도착 리조트, 일정, 차량 정보를 입력합니다.
3. 경로 API와 오피넷 유가로 예상 비용을 계산합니다.
4. 작성자가 자동 계산된 거리·통행료·유가를 확인하고 자동 계산 또는 1인 금액 직접 입력 방식을 선택합니다.
5. 게시글을 등록하고 로그인 사용자 댓글로 세부 내용을 협의합니다.
6. 작성자가 선택한 경우 연락처를 비회원에게도 공개합니다.

## 3. 기능 요구사항

| ID | 요구사항 |
|---|---|
| CP-F-001 | 카풀 모집글 작성은 로그인 회원만 가능해야 합니다. |
| CP-F-002 | 카풀은 기존 게시글의 `CARPOOL` 카테고리와 `CarpoolDetail`을 함께 생성해야 합니다. |
| CP-F-003 | 출발 지역·집결지·도착 리조트·출발 일시를 필수 입력합니다. |
| CP-F-004 | 편도·왕복을 선택하고 왕복이면 복귀 예정 일시를 입력합니다. |
| CP-F-005 | 모집 인원은 운전자를 제외한 양의 정수로 입력합니다. |
| CP-F-006 | 연료 종류·연비·경로·통행료를 사용해 예상 금액을 계산합니다. |
| CP-F-007 | 계산에 사용한 유가와 조회 시각을 저장합니다. |
| CP-F-008 | 경로·유가 정보는 서버가 계산하되 작성자는 자동 분담액 대신 1인 금액을 직접 지정할 수 있어야 합니다. |
| CP-F-009 | 기존 게시글 댓글 API를 통해 로그인 회원만 댓글을 작성합니다. |
| CP-F-010 | 연락처는 선택 입력이며, 작성자가 동의한 경우에만 비회원에게 공개합니다. |
| CP-F-011 | 카풀 목록은 미래 출발 일정만 최신 등록순으로 최대 100페이지까지 조회하며 목록 전용 DTO를 사용합니다. |
| CP-F-012 | 작성자는 장비 적재 가능·불가능 중 하나를 명시하고 목록과 상세에서 이를 확인할 수 있어야 합니다. |
| CP-F-013 | 카풀 댓글은 일반 게시판과 같은 대댓글·수정·삭제·커서 페이징을 지원해야 합니다. |
| CP-F-014 | 메인 화면과 게시판 사이드바에는 출발 시각이 지나지 않은 실제 최신 카풀을 최대 4건 표시하고 등록·상세·전체 목록으로 연결해야 합니다. |
| CP-F-015 | 작성자와 관리자는 카풀 모집글을 수정·삭제할 수 있어야 합니다. 삭제는 기존 `Post`의 소프트 삭제 정책을 사용합니다. |
| CP-F-016 | 카풀 목록은 출발 시각이 지나지 않은 모집글만 제공하고, 상세 정보와 연락처가 포함되지 않은 목록 전용 DTO를 사용합니다. |
| CP-F-017 | 경로 목적지는 카카오 장소 검색의 첫 결과가 아니라 리조트 마스터에 검증해 저장한 스키장 진입 좌표를 사용해야 합니다. |
| CP-F-018 | 오피넷 조회가 불가능하고 유효 캐시도 없으면 사용자가 1,000~3,000원/L 범위의 유가를 입력할 수 있어야 합니다. |
| CP-F-019 | 카카오 지도·길찾기 장애 시 출발지 문자열, 총 이동 거리 1~2,000km, 총 통행료 0~20,000원을 직접 입력해 계산할 수 있어야 합니다. |
| CP-F-020 | 공식·캐시·사용자 유가와 카카오·수동 경로를 구분해 저장하고 상세 화면에 출처를 표시해야 합니다. |

## 4. 비기능 요구사항

- 외부 API 키는 서버에만 보관하며 브라우저에 노출하지 않습니다.
- 공개 장소 검색과 비용 미리보기 API는 IP 단위 호출 제한을 적용해 외부 API 비용과 쿼터를 보호합니다.
- 장소 검색·경로·유가 API가 실패하면 부분 데이터를 저장하지 않고 명확한 오류를 반환합니다. 오피넷은 유효한 캐시가 있을 때만 캐시로 복구합니다.
- 제목 200자, 본문 10,000자, 모집 인원 1~20명, 연비 0.01~100km/L, 직접 지정 1인 금액 1~1,000,000원의 입력 상한을 적용합니다.
- 계산 결과는 게시글에 저장된 스냅샷을 기준으로 재현할 수 있어야 합니다.
- 계산 당시 목적지 좌표를 모집글에 복사해 이후 리조트 기준 좌표가 바뀌어도 계산 근거를 보존합니다.
- 연락처 공개 여부와 연락처 값은 작성자만 수정할 수 있습니다.
- 카풀 상세 정보가 없는 `CARPOOL` 게시글은 저장할 수 없습니다.
- DTO 컬렉션은 방어적 복사를 적용합니다.
- 예외는 `ErrorCode`와 커스텀 예외로 처리합니다.
- 서비스 레이어는 웹 세션을 직접 조작하지 않습니다.

## 5. 제외 범위

신청·승인·좌석 확정·일정 충돌 방지·실시간 채팅·결제는 이번 기능의 성공 조건에 포함하지 않습니다.

## 6. 완료 조건

- 로그인 회원이 카풀 모집글을 등록하고 목록·상세에서 조회할 수 있습니다.
- 작성자와 관리자가 모집글을 수정·삭제할 수 있고 다른 회원의 변경 요청은 거부됩니다.
- 기존 댓글이 카풀 게시글에서도 동작합니다.
- 자동 계산과 직접 지정한 1인 금액이 저장되고 다시 조회됩니다.
- 연락처 비회원 공개 선택이 실제 접근 권한과 일치합니다.
- 오피넷·경로 API 장애 시 게시글이 부분 저장되지 않고 원인을 알 수 있는 오류를 반환합니다.
- 목록 조회용 복합 인덱스와 리조트 기준 좌표가 운영 마이그레이션으로 검증됩니다.
- 두 외부 제공자가 모두 장애여도 제한 범위의 출발지·거리·통행료·유가 입력으로 서버 계산을 완료할 수 있습니다.
