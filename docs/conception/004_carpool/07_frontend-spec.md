# 카풀 프런트엔드 명세

## 1. 목록

기존 게시글 목록과 같은 페이징·검색을 사용하고, 카풀 카드에는 출발 지역·도착 리조트·출발 일시·편도/왕복·모집 인원·1인 예상 비용을 표시합니다.

## 2. 작성 폼

입력 순서는 출발 정보 → 도착 리조트 → 일정 → 차량·비용 → 연락처입니다.

- 왕복 선택 시 복귀 일시 표시
- 경로 자동 계산 버튼과 수동 수정 입력 제공
- 유가 조회 시각 표시
- 계산 결과에 “모집 인원 기준 예상” 표시
- 연락처 비회원 공개 동의 시 개인정보 경고 표시
- 서버 검증 오류는 필드별 표시

## 3. 상세

본문과 카풀 정보를 함께 표시하고, 로그인 사용자에게 댓글 입력을 제공합니다. 연락처는 공개 동의가 있을 때만 표시합니다. 외부 연락처는 새 창 링크와 복사 가능한 텍스트로 제공하되, 전화번호 등 입력 형식은 보존합니다.

## 4. 상태

외부 API 요청 중에는 계산 버튼을 중복 실행하지 않습니다. 자동 계산 실패 시 수동 입력 모드로 전환하고, 기존 저장값이 있는 수정 화면에서는 기존 값을 보존합니다.
