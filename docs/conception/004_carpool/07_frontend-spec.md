# 카풀 프런트엔드 명세

## 1. 목록

페이지당 20건을 표시하고, 카풀 카드에는 출발 지역·도착 리조트·출발 일시·편도/왕복·모집 인원·1인 예상 비용·장비 적재 가능 여부를 표시합니다. 별도 모집 상태를 관리하지 않으므로 `모집중` 배지는 표시하지 않습니다.

## 2. 작성 폼

입력 순서는 출발 정보 → 도착 리조트 → 일정 → 차량·비용 → 연락처입니다.

- 왕복 선택 시 복귀 일시 표시
- 경로 자동 계산 버튼과 1인 금액 직접 지정 방식 제공
- 유가 조회 시각 표시
- 계산 결과에 “모집 인원 기준 예상” 표시
- 연락처 비회원 공개 동의 시 개인정보 경고 표시
- 서버 검증 오류는 필드별 표시
- 장비 적재 가능 여부 체크
- 비로그인 접근 시 회원가입을 기본 행동으로, 로그인을 보조 행동으로 안내
- 카카오 지도 또는 길찾기 장애 시 출발 지역·집결지·총거리·총 통행료 직접 입력 영역 표시
- 오피넷과 유효 캐시가 모두 실패하면 1,000~3,000원/L 유가 직접 입력 영역 표시

## 3. 상세

경로 바로 아래에 모집 인원·총액·1인 금액을 우선 표시하고, 거리·통행료·유가·연료비·장비 적재 여부는 보조 정보로 표시합니다. 본문은 `모집 내용` 카드로 분리합니다. 댓글은 일반 게시판과 같은 대댓글 5건 미리보기, 추가 조회, 수정·삭제, 커서 페이징을 사용합니다. 비익명 댓글은 원형 프로필 이미지를 표시하고 이미지가 없으면 닉네임 첫 글자를 표시합니다. 연락처는 공개 동의가 있을 때만 표시합니다.

## 4. 메인 화면

하드코딩 예시 대신 `GET /api/v1/carpools?page=0&size=4`의 실제 최신 글을 최대 4건 표시합니다. 등록은 `/carpool/new`, 각 항목은 `/carpool/{publicId}`, 전체 보기는 `/carpool`로 연결합니다.

## 5. 상태

주소 검색은 입력 디바운스와 이전 요청 취소를 적용하고, 외부 API 요청 중에는 계산 버튼을 중복 실행하지 않습니다. 외부 API 장애 유형에 따라 경로 또는 유가 수동 입력으로 전환하며 범위 검증 전에는 등록할 수 없습니다. 상세 화면에는 `경로·통행료 사용자 직접 입력`, `오피넷 유효 캐시`, `유가 사용자 직접 입력`을 구분해 표시합니다. 1인 금액 직접 지정 모드에서도 경로·유가 근거는 별도로 저장합니다. 목록 페이지 번호는 한 번에 최대 5개만 표시합니다.
