# 라이브톡 메시지 UI 정리

## 확정 구조

- 내 메시지는 오른쪽, 상대 메시지는 왼쪽에 배치한다.
- 각 메시지 위에 닉네임, 리조트 태그, 시간을 한 줄로 묶어 표시한다.
- 내 메시지에는 별도의 작성자 이름을 표시하지 않는다.
- 리조트 미선택 메시지는 `일반` 태그로 표시한다.
- 메시지 본문은 14px, 메타정보는 11px을 기준으로 한다.
- 메타정보와 말풍선을 가깝게 배치하고 메시지 묶음 사이 간격으로 대화를 구분한다.
- 모바일에서는 말풍선 폭을 제한하고 메타정보가 한 줄 안에서 유지되도록 한다.
- 입력창, 리조트 선택창, 전송 버튼의 높이와 테두리를 통일한다.

## 범위

- 메시지 데이터, WebSocket 연결, 리조트 선택 및 전송 동작은 변경하지 않는다.
- PC·모바일과 라이트·다크 테마에서 같은 정보 구조를 유지한다.

## 검증

- 내 메시지와 상대 메시지 좌우 구분
- 일반 및 리조트 태그 식별
- 긴 메시지와 긴 닉네임의 반응형 표시
- 변경 컴포넌트 ESLint 및 프로덕션 빌드
