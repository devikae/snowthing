# 오늘의 설질 위젯 UI

## 범위

- 홈의 기존 익명게시판 미리보기 영역을 `오늘의 설질` 위젯으로 교체한다.
- 리조트 선택, 한 줄 입력, 등록 버튼을 한 행에 배치한다.
- 제목에는 눈꽃 이모지와 한국 날짜를 표시하고 날짜 변경을 자동 반영한다.
- 당일 설질 제보를 최신순으로 표시하며 고정 높이 안에서 내부 스크롤을 제공한다.
- 각 제보에는 리조트 말머리, 내용, 등록 시각을 표시한다.
- 리조트 말머리는 라이브톡과 동일한 공통 색상 설정을 사용한다.
- 이번 단계에서는 API 요청, 데이터 저장, 인증 처리를 구현하지 않는다.
- 슬로프 선택은 슬로프 마스터 설계 전까지 제공하지 않는다.

## 메뉴 보완

- 게시판 드롭다운과 모바일 메뉴에 `리조트 맛집`을 추가한다.
- 경로는 기존 `FOOD` 게시판 목록을 사용한다.

## 별도 목록 화면

- 홈의 `더보기`는 `/resort-reports`로 이동한다.
- 별도 화면은 당일 설질 제보 목록만 표시하며 게시글 상세 이동을 제공하지 않는다.
- 검색, 페이징, 댓글, 추천, 비추천 UI를 제공하지 않는다.

## 후속 작업

- 설질 제보의 저장 모델과 보존 기간을 확정한 뒤 API를 설계한다.
- 등록 성공·실패 처리와 서버 데이터 목록 갱신은 API 설계 이후 연결한다.
- 추후 `Post` 테이블의 `RESORT_REPORT` 카테고리를 사용하고 입력한 한 줄을 제목과 본문에 동일하게 저장한다.
- 일반 전체글·베스트·검색·게시판 목록과 상세 조회에서는 `RESORT_REPORT`를 제외한다.
