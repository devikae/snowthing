# 회원가입 폼 UI 정리

## 범위

- 회원가입 화면 상단에는 `회원가입` 제목만 표시한다.
- 이메일, 비밀번호, 비밀번호 확인, 닉네임은 필수 항목으로 표시한다.
- 출발 지역, 선호 리조트, 라이딩 성향은 선택 항목으로 표시한다.
- 자기소개는 회원가입 단계에서 입력받지 않는다.
- 출발 지역은 이번 작업에서 기존 문자열 입력 방식을 유지한다.
- 지역 마스터, 지역 선택 API, DB 구조는 변경하지 않는다.

## 화면 구성

- 계정 정보와 선택 정보를 시각적으로 구분한다.
- 필수 표시는 라벨 옆 붉은 `*`, 선택 항목은 작은 `선택` 문구로 통일한다.
- 선호 리조트와 라이딩 성향은 선택 여부가 분명한 카드형 체크 항목으로 표시한다.
- 데스크톱은 2열, 모바일은 1열로 배치한다.

## 검증

- 기존 회원가입 요청과 자동 로그인 동작 유지
- 필수 입력 및 비밀번호 검증 유지
- 반응형 배치와 다크모드 확인
- 변경 파일 ESLint 및 프로덕션 빌드
