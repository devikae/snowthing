# 계산기 카드 화면 (시즌권 본전, 데크 사이즈)

티켓: IKA-113

## 범위

- `/tools/season-pass`, `/tools/deck-size` 두 화면만 바꾼다. 가격표(`/tools/season-pass-prices`)와 도구 목록(`/tools`)은 그대로 둔다.
- 계산 로직(`lib/seasonPass.ts`, `lib/deckSize.ts`)과 공유 링크 형식(`#passPrice=...`, `#weight=...`)은 바꾸지 않는다. 예전에 퍼진 공유 링크도 같은 결과로 열린다.

## 공통 구성

- 화면 크기와 상관없이 한 줄로 쌓는다. 가로 최대 600px, 가운데 정렬.
- 위에서부터: `← 라이더 도구` 링크, 강조색 작은 라벨(계산기 이름), 질문형 제목, 두 줄 설명, 카드 하나.
- 카드 안에 입력과 계산 버튼, 결과가 함께 있다. 결과가 없을 때는 결과 자리에 안내 한 줄을 둔다.
- 강조색은 `--snow-accent`를 쓴다. 다크 모드에서는 밝은 하늘색으로 바뀐다.

## 시즌권 본전 계산기

- 제목: "시즌권, 몇 번 가야 본전일까"
- 입력은 라벨이 왼쪽, 큰 숫자가 오른쪽인 줄 형태다. 리조트 선택, 시즌권 결제액, 리프트권 1회, 다녀온 횟수, 예상 총 방문(선택).
- 결과 문장
  - 본전 N회: "N번째 방문부터 본전" (N만 강조색)
  - 본전 0회(무료 시즌권): "첫 방문부터 이득이에요"
  - 방문할수록 시즌권 쪽이 비싸짐: "갈수록 리프트권이 더 싸요"
  - 회수 불가: "이 조건으로는 본전이 안 나와요"
- "본전"을 쓰는 이유: 계산은 두 비용이 같아지는 회차부터 본전으로 센다. 같아지는 회차는 이득이 아니다.
- 방문 표시: 본전이 15회 이하면 1부터 N까지 동그라미를 그린다. 다녀온 횟수만큼 채우고, N번째는 강조색 테두리다. 15회를 넘으면 막대 하나로 다녀온 비율을 보여준다.
- 카드 아래: 가격표 링크("+ 26/27 시즌 스키장 N곳 ... 가격표도 있어요"), 접힌 "1회 비용과 방문 횟수별 비교", 공유 버튼, 계산 방법 설명.
- 화면 문구는 "개별권" 대신 "리프트권"으로 통일한다.

## 데크 사이즈 계산기

- 제목: "내 데크는 몇 cm가 맞을까"
- 입력은 체중, 부츠 사이즈 타일 두 칸이다. 숫자 바로 뒤에 단위를 붙인다. 380px 이하에서는 한 칸씩 쌓는다.
- 결과: 진한 블록 안에 참고 범위를 크게, 그 아래 "Nkg에 겹치는 N개 구간의 범위예요".
- 블록 아래에 짧은 쪽, 중간, 긴 쪽 세 줄(라벨, 길이, 용도). 구간을 나누지 못하면 안내 문장 하나.
- 결과 블록 색: 라이트는 `#0f172a`, 다크는 `--snow-surface-mid`.
- 카드 아래: 선택 방향 설명, 공유 버튼, 모델 비교와 질문 초안(결과가 있을 때), 자료 출처.

## 하지 않는 것

- 결과를 홍보 카드 이미지로 저장하는 기능.
- 입력하는 즉시 계산하기. 입력 도중 오류 문구가 깜빡이지 않도록 계산 버튼을 유지한다.
