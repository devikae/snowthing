# Work Log Skill

## 기록 위치

모든 프로젝트 작업 기록은 다음 파일을 기본으로 사용한다.

`docs/project/work.md`

## 기록 시점

작업 단위를 기준으로 다음 시점에 갱신한다.

1. 계획 확정 시 TODO 등록
2. 구현 중 주요 이슈 발견 시
3. 사용자 결정이 필요한 항목 발생 시
4. 구현 완료 시
5. 검증 완료 또는 실패 시

## 기록 형식

```md
## 작업명

- 상태: TODO | IN_PROGRESS | BLOCKED | DONE
- 시작일: YYYY-MM-DD

### 계획
- ...

### 완료
- ...

### 남은 작업
- ...

### 이슈
- ...

### 결정 필요
- ...

### 검증
- ...
```

## 원칙

- 완료하지 않은 작업을 완료로 기록하지 않는다.
- 실제로 검증하지 않은 항목을 검증 완료로 기록하지 않는다.
- 발견된 이슈를 숨기지 않는다.
- 사용자 결정을 기다리는 항목은 BLOCKED 또는 결정 필요 항목으로 명시한다.
