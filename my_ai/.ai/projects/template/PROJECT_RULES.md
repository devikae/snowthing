# Project Rules Template

## 1. 프로젝트 개요

프로젝트 목적, 기술 스택, 주요 도메인, 현재 진행 상태를 기록한다.

## 2. 프로젝트 작업 시작 시 필수 문서 확인

새로운 기능 또는 모듈을 개발할 때 `docs/conception/` 하위의 모든 설계 문서를 전수 검토한다.

검토 대상에는 최소한 다음이 포함된다.

- 도메인 모델
- ERD
- API 명세서
- 상태값/Enum 정의
- 권한 정책
- 주요 비즈니스 규칙
- 기존 작업 문서

## 3. 100% 대조·검증 규칙

구현 계획 수립 전에 설계 문서와 실제 구현 요구사항을 대조한다.

특히 다음을 확인한다.

- 누락된 필드
- N:M 중계 관계
- FK 관계
- 필수/선택 값
- 상태 전이
- 마스터 API 스펙
- 요청/응답 DTO
- 권한 및 인증 조건
- Unique 제약
- 인덱스 필요성

독단적인 스펙 생략이나 임의 구현을 금지한다.

설계 문서와 코드가 충돌하면 AI가 임의로 어느 한쪽을 정답으로 선택하지 않고 사용자에게 보고한다.
