# AI Skill Rules Set

이 폴더는 학습용 개발 프로젝트에서 사용할 AI 공통 Rule 및 Skill 세트입니다.

## 핵심 흐름

1. `.ai/RULES.md` 읽기
2. 해당 프로젝트의 `PROJECT_RULES.md` 읽기
3. 작업 관련 Skill 읽기
4. 코드 및 설계 문서 분석
5. 계획 설명
6. 사용자 승인
7. 파일 수정
8. 검증
9. `docs/project/work.md` 작업 기록

## 학습 문서 파일명

`study{YYMMDD}-{메인토픽}-{서브토픽}.md`

예:

- `study260824-JPA-페이징.md`
- `study260824-스프링시큐리티-필터체인.md`
- `study260824-데이터베이스-인덱스.md`

메인토픽과 서브토픽은 가능한 한 한글을 우선 사용하되, JPA/JWT/DTO/API/SQL 등 공식 약어나 기술명은 원형을 유지할 수 있습니다.
